## 三、遗留 / 已知问题（建议下轮，未在本轮改动）

| 编号 | 严重度 | 说明 | 建议 |
|------|--------|------|------|
| **C1** | 高（业务边界） | 登录为纯 UI 壳（`localStorage 'tea-logged-in'`），后端零鉴权 | 单机演示可接受；若联网 / 多用户需加真实登录门禁。本轮已在审查中确认，未擅自改动 |
| **CR-02** | 中 | 退货业务语义为「退供应商」，非「客户退货闭环」（无客户退货、退款流水） | 需产品澄清后设计闭环 |
| **IM-01** | 中 | 会员折扣口径不一致：`discount_rate`（等级折扣）与 `member_price`（单位会员价）并存 | 统一口径，明确优先级 |
| **IM-03** | 低 | 积分计算 `Math.floor(amount)` 截断，未四舍五入 | 确认业务规则后决定是否四舍五入 |
| **I4** | 低 | 单位换算默认 1 | **已验证**：换算强制 `> 0` 且销售 / 退货 / 入库均按 `conversion_to_base` 正确换算，无默认 1 路径，判为 by-design，不改 |
| **I5** | 低 | 库存报损 `grams` 为 `i64`，不允许小数 | 茶叶按整数克 / 件计，无需小数；如需小数需 `f64` 全链路改造，建议下轮评估 |
| **I6** | 中 | 组合支付（多支付方式分摊）前后端口径可能不一致 | 确认后对齐 |
| **I7** | 低 | 浮点金额累计 | 已用 `utils/money.rs::round2` 在聚合 / 落库边界收敛 `f64` 漂移，持续观察 |
| **S-4 / S-5** | 中 | 无真实认证；密码以 base64 明文存 localStorage | 单机可接受；生产需加密存储 |
| **S-6** | 中 | Tauri `CSP` 为 `null` | 生产构建应配置严格 CSP |
| **S-7 / S-8 / S-9** | 中 | PII 明文存储 / 数据库明文 / `qrcode` 潜在 ReDoS | 安全加固项，下轮规划 |
