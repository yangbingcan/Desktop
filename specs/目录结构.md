## 目录说明

### src/ 前端目录

| 目录 | 说明 |
|------|------|
| `assets/` | 静态资源（图片、全局样式） |
| `components/` | 公共组件，分 common（通用）和 business（业务） |
| `views/` | 页面组件，按业务模块划分 |
| `stores/` | Pinia 状态管理 |
| `router/` | Vue Router 路由配置 |
| `types/` | TypeScript 类型定义 |
| `utils/` | 工具函数（价格计算、条码生成、打印） |
| `api/` | Tauri Commands 封装调用 |

### src-tauri/ Rust 后端目录

| 目录 | 说明 |
|------|------|
| `commands/` | Tauri 命令层（暴露给前端调用） |
| `db/` | 数据库层（Schema、迁移、查询） |
| `models/` | 数据模型（结构体定义） |
| `services/` | 业务逻辑服务（库存FIFO、价格计算等核心逻辑） |

## 命名规范

### 目录命名

- 目录名统一使用 **kebab-case**（如 `print-templates`、`bar-codes`）
- 业务模块目录使用复数名词（如 `products`、`members`、`sales`）

### 文件命名

| 类型 | 规范 | 示例 |
|------|------|------|
| Vue 组件 | PascalCase | `ProductList.vue`、`MemberCard.vue` |
| TypeScript 文件 | camelCase | `productStore.ts`、`inventoryService.ts` |
| Rust 文件 | snake_case | `inventory_service.rs`、`products.rs` |
| 样式文件 | kebab-case | `global-styles.css`、`theme-vars.css` |
