## 三、业务规则

### 3.1 计价规则

```
商品金额 = Σ(销售单位零售价 × 数量)
如果会员：
  实付金额 = 商品金额 × 会员折扣率
  积分 = 实付金额（向下取整）
如果使用积分抵扣：
  抵扣金额 = 抵扣积分 / 100
  实付金额 = 商品金额 × 会员折扣率 - 抵扣金额
```

### 3.2 会员等级折扣

| 等级 | 折扣率 |
|------|--------|
| 普通 | 100%（无折扣） |
| 银卡 | 95% |
| 金卡 | 90% |

### 3.3 库存扣减规则

- 销售完成后立即扣减库存
- 使用 FIFO 先进先出扣减批次
- 库存不足时提示但不阻止（允许欠库存）

## 六、技术实现要点

### 6.1 销售流程

```rust
async fn create_sale_order(
    conn: &Connection,
    input: SaleOrderInput,
) -> Result<SaleOrder, String> {
    // 1. 开启事务
    conn.execute("BEGIN TRANSACTION", [])?;

    // 2. 计算金额
    let total = calculate_total(&input.items);
    let discount = apply_member_discount(total, &input.member)?;
    let actual = total - discount - points_deduct;

    // 3. 创建订单
    let order_id = Uuid::new_v4().to_string();
    insert_sale_order(conn, &order_id, &input)?;

    // 4. 扣减库存（FIFO）
    for item in &input.items {
        deduct_inventory(conn, &item.product_id, item.grams)?;
    }

    // 5. 记录积分变动
    if let Some(member_id) = &input.member_id {
        update_member_points(conn, member_id, points_earned)?;
    }

    // 6. 提交事务

}
```
