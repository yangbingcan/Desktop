# v0.4.0 UI 迭代升级 - 任务规划

> **目标**：在 v0.3.6 基础上，参考 JXC 完成 UI 框架升级

> **关键路径**：CSS 变量 → 状态 → 布局 → 标签栏 → 侧栏 → 主题
