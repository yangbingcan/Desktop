# 商品档案功能需求

> **功能模块**：商品档案（商品录入）
> **优先级**：P0（核心功能）
> **开发时间**：5天

---

## 一、功能概述

商品档案是整个茶叶店管理系统的基础数据模块，用于管理茶叶商品信息。由于茶叶既有按"克/斤"卖的散茶，也有按"罐/盒/件"卖的礼盒，还有茶具等计件商品，因此必须支持灵活的多规格定义。

---

## 二、业务背景

### 2.1 商品类型

| 类型 | 说明 | 库存计算方式 | 基准单位 |
|------|------|-------------|---------|
| 称重类 | 散茶，按克/斤销售 | 累计/扣减克数 | 克（g） |
| 计件类 | 礼盒、茶具，按个/件销售 | 累计/扣减个数 | 个（pcs） |

### 2.2 多单位换算

每个商品必须设定一个**基准单位**，然后可添加多个**销售单位**及换算关系：

| 单位名称 | 换算为基准单位 | 零售价（元） | 会员价（元） |
|:---|:---|:---|:---|
| 克（基准） | 1 g | 0.8 | 0.75 |
| 两（50g） | 50 g | 40 | 37 |
| 斤（500g） | 500 g | 380 | 350 |
| 罐（250g） | 250 g | 200 | 180 |
| 件（20罐） | 5000 g | 3800 | 3600 |

> **规则**：前台销售时按销售单位展示和计价，但底层库存全部折算为基准单位（克/个）累加或扣减。

## 三、功能需求

### 3.1 商品列表

**功能点**：
- 显示商品列表（表格形式）
- 支持按分类筛选（一级/二级分类）
- 支持按商品类型筛选（称重类/计件类）
- 支持关键词搜索（商品名称/编码）
- 支持分页
- 显示库存数量（根据基准单位显示）

**界面字段**：

| 字段 | 说明 |
|------|------|
| 编码 | 商品编码 |
| 名称 | 商品名称 |
| 分类 | 商品分类（一级>二级） |
| 类型 | 称重类/计件类 |
| 默认单位 | 默认销售单位 |
| 库存 | 当前库存数量 |
| 操作 | 编辑/删除 |

### 3.2 新增商品

**功能点**：
- 填写商品基本信息
- 选择商品分类
- 设置商品类型（称重类/计件类）
- 添加销售单位（至少一个，可多个）
- 设置产地、年份、等级等信息
- 上传商品图片（可选）

**表单字段**：

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| 商品名称 | 文本 | ✅ | 中文名 |
| 商品分类 | 选择 | ✅ | 一级分类 |
| 商品类型 | 单选 | ✅ | 称重类/计件类 |
| 产地 | 文本 | 否 | 自由文本 |
| 年份 | 文本 | 否 | 如：2023春 |
| 等级 | 文本 | 否 | 如：特级、一级 |
| 发酵程度 | 下拉选择 | 否 | 不发酵/轻发酵/半发酵/全发酵 |
| 焙火程度 | 下拉选择 | 否 | 轻火/中火/足火/重火 |
| 商品图片 | 图片上传 | 否 | 支持1张主图 |
| 销售单位 | 动态列表 | ✅ | 至少添加一个 |

**销售单位子表单**：

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| 单位名称 | 文本 | ✅ | 如：罐、两、斤、件 |
| 换算数量 | 数字 | ✅ | 换算为基准单位的数量 |
| 零售价 | 金额 | ✅ | 元，保留两位小数 |
| 会员价 | 金额 | ✅ | 元，保留两位小数 |

**验证规则**：
- 商品名称不能为空
- 至少添加一个销售单位
- 销售单位的换算数量必须 > 0
- 零售价和会员价必须 >= 0

### 3.3 编辑商品

**功能点**：
- 加载商品现有信息
- 修改商品基本信息和销售单位
- 支持新增/删除/修改销售单位

**特殊规则**：
- 如果商品已有库存记录，商品类型不允许修改

### 3.4 删除商品

**功能点**：
- 删除商品前检查是否有库存记录
- 如果有库存记录，提示"该商品存在库存记录，无法删除"
- 确认后删除商品及其销售单位

### 3.5 商品分类管理

**功能点**：
- 管理商品一级分类
- 管理商品二级分类（挂在一级下）
- 支持新增/编辑/删除分类
- 分类排序

**分类结构**：

```
├── 青茶
│   ├── 武夷岩茶
│   ├── 铁观音
│   └── 凤凰单丛
├── 红茶
│   ├── 正山小种
│   └── 祁门红茶
├── 普洱
│   ├── 生普
│   └── 熟普
└── 绿茶
```

## 四、数据模型

### 4.1 商品表（products）

| 字段 | 类型 | 说明 |
|------|------|------|
| id | TEXT | 主键 UUID |
| code | TEXT | 商品编码（SP+日期+序号） |
| name | TEXT | 商品名称 |
| category_id | TEXT | 分类ID |
| type | TEXT | 类型：weight/count |
| base_unit | TEXT | 基准单位：g/pcs |
| origin | TEXT | 产地 |
| year | TEXT | 年份 |
| grade | TEXT | 等级 |
| fermentation_level | TEXT | 发酵程度 |
| roast_level | TEXT | 焙火程度 |
| image_url | TEXT | 图片URL |
| default_unit_id | TEXT | 默认销售单位ID |
| is_active | INTEGER | 是否启用：1/0 |
| created_at | TEXT | 创建时间 |
| updated_at | TEXT | 更新时间 |

### 4.2 销售单位表（sales_units）

| 字段 | 类型 | 说明 |
|------|------|------|
| id | TEXT | 主键 UUID |
| product_id | TEXT | 商品ID |
| name | TEXT | 单位名称 |
| conversion_to_base | INTEGER | 换算为基准单位的数量 |
| retail_price | REAL | 零售价 |
| member_price | REAL | 会员价 |
| sort_order | INTEGER | 排序 |

### 4.3 商品分类表（product_categories）

| 字段 | 类型 | 说明 |
|------|------|------|
| id | TEXT | 主键 UUID |
| name | TEXT | 分类名称 |
| parent_id | TEXT | 父级分类ID（一级为NULL） |
| level | INTEGER | 层级：1/2 |
| sort_order | INTEGER | 排序 |

## 六、技术实现

### 6.1 前端实现

- **框架**：Vue 3 + TypeScript
- **UI库**：Naive UI
- **样式**：UnoCSS 原子化 CSS
- **路由**：Vue Router
- **组件**：
  - `ProductList.vue` - 商品列表
  - `ProductForm.vue` - 商品表单（新增/编辑）
  - `CategoryManager.vue` - 分类管理

### 6.2 后端实现

- **框架**：Rust + Tauri 2.x
- **数据库**：SQLite
- **Command**：
  - `get_products` - 获取商品列表
  - `get_product` - 获取单个商品
  - `create_product` - 创建商品
  - `update_product` - 更新商品
  - `delete_product` - 删除商品
  - `get_categories` - 获取分类
  - `create_category` - 创建分类
  - `update_category` - 更新分类
  - `delete_category` - 删除分类
