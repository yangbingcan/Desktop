## 二、任务详情

### T-01: 创建数据库模块

**文件**：`src-tauri/src/db/mod.rs`

**内容**：
```rust
//! 数据库模块
//! 
//! 管理数据库连接、初始化、迁移等

use rusqlite::Connection;
use std::sync::Mutex;

pub struct Database {
    pub conn: Mutex<Connection>,
}

impl Database {
    pub fn new(path: &str) -> Result<Self, String> {
        let conn = Connection::open(path)
            .map_err(|e| e.to_string())?;
        Ok(Database { conn: Mutex::new(conn) })
    }
}
```
