## 三、关键实现要点

### 3.1 输入校验（[sales.rs:15-55](file:///d:/AI/AI/开发/茶叶店管理/tea-manage/src-tauri/src/commands/sales.rs#L15-L55)）

- 手机号：11 位数字、1 开头、第二位 3-9
- 姓名：非空（trim 后）
- 销售明细：至少 1 条、数量 > 0

### 3.2 会员等级自动升级（关联 M03）

- 累计消费 ≥ 1000 → 银卡（95% 折扣）
- 累计消费 ≥ 5000 → 金卡（90% 折扣）
- 升级判断写入 `create_sale_order` 事务内

### 3.3 软删除策略

- `members.is_active = 0` 即视为删除
- 查询/识别时全部带 `WHERE is_active = 1`
- 消费记录通过 `sales_orders.member_id` 关联保留

### 3.4 偏好数据格式

- 偏好茶类 / 口感 / 消费场景：JSON 数组字符串存储
- 禁忌 / 冲泡习惯：纯文本
- 读写时通过 `serde_json::from_str` / `to_string` 转换
