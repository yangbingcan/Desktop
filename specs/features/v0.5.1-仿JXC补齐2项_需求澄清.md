# v0.5.1 需求澄清 - JXC 补齐 2 项

> **版本号**：v0.5.1
> **类型**：patch（仿 JXC 第二轮补齐 - 2 项 UI 微调）
> **前置版本**：v0.5.0
> **发起时间**：2026-07-04
> **状态**：✅ 需求已澄清

---

## 一、版本定位

v0.5.0 已完成 10 项视觉/交互升级（毛玻璃/动效/工作台/弹窗美化/侧栏深浅态/分组激活/折叠弹窗/登录页骨架/Naive UI 全套覆盖），但仍欠 2 项仿 JXC 的微调。v0.5.1 是一次**纯 UI 补齐**的 patch 版本：

1. **侧栏树状分组连线** — 子项左侧 1px dashed 主色竖线（仿 JXC `gl-sidebar-group-line`）
2. **登录页扩展** — 15 个散点光斑 + 主题切换按钮 + 记住密码 + 上次用户名回填

### 1.1 设计原则
- 范围限定：仅前端 UI，不动业务逻辑
- 性能优先：CSS-only 效果优先，避免大改组件
- 茶文化延续：登录页文案/视觉与 v0.5.0 已建好的极光+卡片风格统一
- 不引入新依赖

## 二、需求项

### 2.1 侧栏树状分组连线

#### 现状
- v0.5.0 侧栏展开态：分组标题 + 直接列出所有菜单项
- 各菜单项之间无视觉关联，看上去是"扁平列表"而非"树状分组"

#### 期望
- 子项（菜单项）左边加 1px 竖线作为"从属分组"的视觉指示
- 样式：dashed（虚线），主色 30% 透明度
- 仅展开态显示（折叠态不显示，因折叠后用 ::after 网格占位）
- 不与现有"分组激活竖条"冲突（竖条是分组标题左侧，连线是子项左侧）

#### 验收标准（AC）
- [ ] **AC-L1** 展开态侧栏，每个分组的子项整体左边显示 1px dashed 竖线
- [ ] **AC-L2** 竖线颜色：主色 30% 透明度
- [ ] **AC-L3** 竖线位置：距离侧栏左边缘 12px（即 menu padding 之内）
- [ ] **AC-L4** 竖线高度：与子项列表等高
- [ ] **AC-L5** 折叠态不显示该连线
- [ ] **AC-L6** 切主色（茶金/竹青/朱砂）时竖线颜色自动跟随
- [ ] **AC-L7** 切深色模式时竖线适配深色背景
- [ ] **AC-L8** 与"分组激活竖条"互不冲突（一个在分组标题左侧，一个在子项列表整体左侧）
- [ ] **AC-L9** 动画与现有 spring 曲线一致（无新增动画）
- [ ] **AC-L10** 不影响菜单项的点击/hover 区域

#### 不做
- 不在折叠态 portal 弹窗中显示连线
- 不在搜索结果模式显示连线
- 不调整分组标题样式

### 2.2 登录页扩展

#### 现状（v0.5.0）
- 4 层装饰：极光背景 / 网格 / 噪点 / **3 个固定光点**
- 登录卡片：渐变 + 茶叶 Logo + 标题 + 副标题 + 下划线输入框 + 按钮
- 无主题切换、无记住密码

#### 期望

##### 2.2.1 散点光斑（v0.5.0: 3 个 → v0.5.1: 15 个）
- 数量：15 个散点
- 位置：随机但固定坐标（百分比定位），覆盖整个登录区域
- 样式：圆形 3-5px 直径，主色（茶金/竹青/朱砂）
- 动画：每个点有独立 delay + duration（3-4s），呼吸效果（透明度 0.3-0.7 循环）
- 性能：使用 CSS 动画 + 透明度，避免重排

##### 2.2.2 主题切换按钮
- 位置：登录卡片右上角
- 图标：太阳/月亮（Sunny/Moon）
- 行为：点击切换 `themeMode`（light ↔ dark）
- 视觉：圆形按钮 + 毛玻璃背景，hover 抬升

##### 2.2.3 记住密码
- 表单新增 checkbox：「记住密码」
- 行为：
  - 勾选时：localStorage 保存 `tea-remember=true` + `tea-last-username` + `tea-last-password`
  - 不勾选：清空保存
- 加密：base64 编码即可（本地单机版，无强安全需求）

##### 2.2.4 上次用户名回填
- 进入登录页时自动读取 `tea-last-username` 回填
- 勾选「记住密码」时同时回填密码
- 不勾选时只回填用户名

##### 2.2.5 主题跟随（如果用户切了主色，登录页装饰色也跟随）
- 15 个光斑的颜色用 `var(--tea-primary)` 而非硬编码 #C4956A
- 极光背景渐变也是变量驱动
- 验证：切到竹青主题后，登录页光斑变绿色

#### 验收标准（AC）
- [ ] **AC-LOGIN-1** 登录页渲染 15 个散点光斑（不是 3 个）
- [ ] **AC-LOGIN-2** 光斑位置随机但固定（刷新后位置不变）
- [ ] **AC-LOGIN-3** 光斑有呼吸动画（透明度循环）
- [ ] **AC-LOGIN-4** 主题切换按钮在登录卡片右上角
- [ ] **AC-LOGIN-5** 点击主题切换按钮后，登录页立即变成深色（极光/卡片/光斑全部跟随）
- [ ] **AC-LOGIN-6** 表单含「记住密码」checkbox
- [ ] **AC-LOGIN-7** 勾选记住密码后「登录」按钮触发时，localStorage 保存用户名+密码（base64 编码）
- [ ] **AC-LOGIN-8** 刷新登录页后，localStorage 有数据则自动回填用户名
- [ ] **AC-LOGIN-9** 刷新登录页后，若勾选过记住密码则同时回填密码
- [ ] **AC-LOGIN-10** 不勾选记住密码时，刷新后只回填用户名
- [ ] **AC-LOGIN-11** 切主色（茶金/竹青/朱砂）后，15 个光斑颜色跟随变化
- [ ] **AC-LOGIN-12** 切深色模式后，登录卡片的极光背景光斑颜色适配深色（更亮）
- [ ] **AC-LOGIN-13** 登录按钮触发后跳转到首页（v0.5.0 已实现，复用即可）

#### 不做
- 不做密码强度校验
- 不做"忘记密码"流程
- 不做多账号切换
- 不做"验证码"功能
- 不做 token 鉴权（v0.5.0 已是公开页，登录按钮仅是导航作用）
