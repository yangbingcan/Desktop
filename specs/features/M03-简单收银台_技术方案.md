## 一、概述

收银台是茶叶店日常销售的核心操作界面，提供商品录入、计价、折扣应用、支付收款等功能。

## 二、数据库设计

### 2.1 新增表

#### 销售单据表 (sales_orders)

```sql
CREATE TABLE sales_orders (
    id TEXT PRIMARY KEY NOT NULL,
    order_no TEXT NOT NULL UNIQUE,
    member_id TEXT,
    member_name TEXT,
    total_amount REAL NOT NULL DEFAULT 0,
    discount_amount REAL NOT NULL DEFAULT 0,
    points_deduct INTEGER NOT NULL DEFAULT 0,
    points_earned INTEGER NOT NULL DEFAULT 0,
    actual_amount REAL NOT NULL DEFAULT 0,
    pay_method TEXT,
    pay_status TEXT NOT NULL DEFAULT 'pending',
    status TEXT NOT NULL DEFAULT 'pending',
    remark TEXT,
    created_at TEXT NOT NULL DEFAULT (datetime('now')),
    FOREIGN KEY (member_id) REFERENCES members(id) ON DELETE SET NULL
);

CREATE INDEX idx_sales_order_no ON sales_orders(order_no);
CREATE INDEX idx_sales_member ON sales_orders(member_id);
CREATE INDEX idx_sales_status ON sales_orders(status);
CREATE INDEX idx_sales_created ON sales_orders(created_at);
```

#### 销售明细表 (sales_items)

```sql
CREATE TABLE sales_items (
    id TEXT PRIMARY KEY NOT NULL,
    order_id TEXT NOT NULL,
    product_id TEXT NOT NULL,
    product_name TEXT NOT NULL,
    unit_id TEXT NOT NULL,
    unit_name TEXT NOT NULL,
    quantity INTEGER NOT NULL DEFAULT 1,
    unit_price REAL NOT NULL DEFAULT 0,
    grams INTEGER NOT NULL DEFAULT 0,
    subtotal REAL NOT NULL DEFAULT 0,
    created_at TEXT NOT NULL DEFAULT (datetime('now')),
    FOREIGN KEY (order_id) REFERENCES sales_orders(id) ON DELETE CASCADE,
    FOREIGN KEY (product_id) REFERENCES products(id) ON DELETE CASCADE
);

CREATE INDEX idx_sales_item_order ON sales_items(order_id);
```

#### 会员表 (members)

```sql
CREATE TABLE members (
    id TEXT PRIMARY KEY NOT NULL,
    name TEXT NOT NULL,
    phone TEXT NOT NULL UNIQUE,
    gender TEXT,
    birthday TEXT,
    level TEXT NOT NULL DEFAULT 'normal' CHECK (level IN ('normal', 'silver', 'gold')),
    points INTEGER NOT NULL DEFAULT 0,
    balance REAL NOT NULL DEFAULT 0,
    total_consume REAL NOT NULL DEFAULT 0,
    consume_count INTEGER NOT NULL DEFAULT 0,
    last_visit TEXT,
    is_active INTEGER NOT NULL DEFAULT 1,
    created_at TEXT NOT NULL DEFAULT (datetime('now')),
    updated_at TEXT NOT NULL DEFAULT (datetime('now'))
);

CREATE INDEX idx_member_phone ON members(phone);
CREATE INDEX idx_member_level ON members(level);
```

### 2.2 会员等级折扣

| 等级 | 字段值 | 折扣率 |
|------|--------|--------|
| 普通 | normal | 100% |
| 银卡 | silver | 95% |
| 金卡 | gold | 90% |

## 三、API 设计

### 3.1 销售相关 Commands

| Command | 参数 | 返回值 | 说明 |
|---------|------|--------|------|
| `create_sale_order` | SaleOrderInput | SaleOrder | 创建销售订单 |
| `get_sale_orders` | page, page_size, date | PageResult | 查询销售订单 |
| `get_sale_order_detail` | order_id | SaleOrderDetail | 订单详情 |
| `cancel_sale_order` | order_id | Result | 取消订单 |
| `hold_order` | SaleOrderInput | string | 挂单 |
| `get_held_orders` | - | SaleOrder[] | 获取挂起订单 |
| `resume_order` | order_id | SaleOrder | 取单 |

### 3.2 会员相关 Commands

| Command | 参数 | 返回值 | 说明 |
|---------|------|--------|------|
| `get_member_by_phone` | phone | Member | 按手机号查询会员 |
| `create_member` | MemberInput | Member | 创建会员 |
| `update_member` | id, MemberUpdate | Member | 更新会员 |
| `deduct_points` | member_id, points | Result | 扣减积分 |

### 3.3 数据结构

```rust
/// 销售订单输入
struct SaleOrderInput {
    items: Vec<SaleItemInput>,
    member_id: Option<String>,
    points_deduct: Option<i64>,
    pay_method: Option<String>,
    remark: Option<String>,
}

/// 销售明细输入
struct SaleItemInput {
    product_id: String,
    unit_id: String,
    quantity: i64,
}

/// 销售订单
struct SaleOrder {
    id: String,
    order_no: String,
    member_id: Option<String>,
    member_name: Option<String>,
    total_amount: f64,
    discount_amount: f64,
    points_deduct: i64,
    points_earned: i64,
    actual_amount: f64,
    pay_method: Option<String>,
    status: String,
    remark: Option<String>,
    items: Vec<SaleOrderItem>,
    created_at: String,
}

/// 销售明细
struct SaleOrderItem {
    id: String,
    product_id: String,
    product_name: String,
    unit_name: String,
    quantity: i64,
    unit_price: f64,
    grams: i64,
    subtotal: f64,
}

/// 会员
struct Member {
    id: String,
    name: String,
    phone: String,
    gender: Option<String>,
    birthday: Option<String>,
    level: String,
    points: i64,
    balance: f64,
    total_consume: f64,
    consume_count: i64,
    last_visit: Option<String>,
    created_at: String,
}

/// 会员输入
struct MemberInput {
    name: String,
    phone: String,
    gender: Option<String>,
    birthday: Option<String>,
}
```
