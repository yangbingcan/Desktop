## 三、关键修复记录（CR）

| 编号 | 问题 | 修复 |
|------|------|------|
| CR-04 | 销售订单事务嵌套 | 改用单层 `BEGIN EXCLUSIVE TRANSACTION` 包裹整个函数 |
| CR-05 | `query_map` 回调中 `unwrap` 风险 | 改用 `collect::<Result<Vec<_>, _>>()` 统一处理 |
| CR-06 | 积分抵扣规则 | 100 积分 = 1 元，抵扣金额 = 积分数 / 100，余额不变 |
| CR-07 | 积分/金额校验 | 校验非负，超额返回明确错误 |
| CR-08 | 余额保护 | 扣减前校验 `balance >= 扣减金额` |
| CR-09 | 等级自动升级 | 累计消费 ≥ 1000 → 银卡，≥ 5000 → 金卡 |
| CR-09b | FIFO 余量校验 | 批次循环扣减后校验 `remaining == 0` |
| CR-13 | 订单号并发重复 | 订单号加毫秒后缀 `XS{YYYYMMDDHHMMSS}{MMM}` |
| CR-14 | 折扣率统一 | 使用 `MemberLevel::discount_rate()` 单一来源 |

## 六、备注

3. **防超卖**：库存扣减前必须检查库存是否充足
