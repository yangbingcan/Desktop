# M05 - 会员管理

> **功能模块**：会员管理
> **优先级**：P1
> **依赖模块**：M03-简单收银台
> **创建日期**：2026-07-01

---

## 一、功能概述

会员管理是茶叶店做私域复购的核心工具，记录会员基础档案、口味偏好和消费历史，让店员能够个性化服务会员。

### 1.1 核心价值

- **快速识别**：手机号/会员码快速识别会员身份
- **精准推荐**：基于口味偏好档案，店员可一眼了解会员喜好
- **积分营销**：消费得积分，积分可抵扣，增强会员粘性

---

## 二、业务规则

### 2.1 会员等级与折扣

| 等级 | 折扣率 | 升级条件 |
|------|--------|---------|
| 普通（normal） | 100%（无折扣） | 注册即为普通 |
| 银卡（silver） | 95% | 累计消费满 1000 元 |
| 金卡（gold） | 90% | 累计消费满 5000 元 |

### 2.2 积分规则

- 消费 1 元 = 1 积分
- 100 积分 = 1 元（可抵扣）
- 积分不可提现

### 2.3 储值规则

- 会员可充值储值余额
- 储值余额可用于消费扣款
- 储值扣款不产生积分

## 三、功能清单

### 3.1 会员档案

| 功能 | 说明 |
|------|------|
| 会员列表 | 显示所有会员，支持搜索、分页 |
| 新增会员 | 手机号、姓名、性别、生日 |

| 删除会员 | 软删除（is_active=0） |

### 3.2 口味偏好

| 功能 | 说明 |
|------|------|
| 偏好茶类 | 多选标签（岩茶、单丛、普洱等） |
| 口感倾向 | 多选标签（浓醇/清香/回甘等） |
| 禁忌 | 文本备注（不喝什么） |
| 冲泡习惯 | 文本备注 |
| 消费场景 | 多选（自饮/送礼/办公） |
| 常购清单 | 最近购买的商品列表 |
| 到店频率 | 系统计算平均到店天数 |

### 3.3 消费记录

| 功能 | 说明 |
|------|------|
| 消费历史 | 显示会员所有消费订单 |
| 积分变动 | 显示积分获取和使用记录 |
| 储值变动 | 显示充值和消费记录 |

## 四、数据结构

### 4.1 会员表 (members)

| 字段 | 类型 | 说明 |
|------|------|------|
| id | TEXT | 主键 UUID |
| name | TEXT | 姓名 |
| phone | TEXT | 手机号（唯一） |
| gender | TEXT | 性别 |
| birthday | TEXT | 生日 |
| level | TEXT | 等级（normal/silver/gold） |
| points | INTEGER | 积分余额 |
| balance | REAL | 储值余额 |
| total_consume | REAL | 累计消费金额 |
| consume_count | INTEGER | 消费次数 |
| last_visit | TEXT | 最后到店时间 |
| is_active | INTEGER | 是否有效（1/0） |
| created_at | TEXT | 创建时间 |
| updated_at | TEXT | 更新时间 |

### 4.2 会员口味偏好表 (member_preferences)

| 字段 | 类型 | 说明 |
|------|------|------|
| id | TEXT | 主键 UUID |
| member_id | TEXT | 会员ID |
| preferred_teas | TEXT | 偏好茶类（JSON数组） |
| taste_preferences | TEXT | 口感倾向（JSON数组） |
| taboos | TEXT | 禁忌 |
| brew_habits | TEXT | 冲泡习惯 |
| consumption_scenario | TEXT | 消费场景（JSON数组） |
| remark | TEXT | 备注 |
| updated_at | TEXT | 更新时间 |

```typescript
async function getMemberByPhone(phone: string): Promise<Member | null> {
    return await invoke('get_member_by_phone', { phone })
}
```

### 6.2 会员等级计算

```rust
fn calculate_level(total_consume: f64) -> MemberLevel {
    if total_consume >= 5000.0 {
        MemberLevel::Gold
    } else if total_consume >= 1000.0 {
        MemberLevel::Silver
    } else {
        MemberLevel::Normal
    }
}
```
