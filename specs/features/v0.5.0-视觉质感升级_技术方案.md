# v0.5.0 视觉质感升级 - 技术方案

> **版本号**：v0.5.0
> **类型**：minor（视觉质感升级）
> **前置版本**：v0.4.0
> **创建日期**：2026-07-04

---

## 一、目标

在 v0.4.0 已有的 UI 框架基础上，通过**纯 CSS 样式升级 + 少量组件改动**，实现：
1. 全局毛玻璃（Glass Morphism）体系
2. 微交互细节（指示线、hover 抬升、spring 曲线）
3. 工作台欢迎页（Hero + 快捷操作 + 数据概览）
4. Ant Design 弹窗/抽屉美化覆盖
5. 品牌位置调整（标题栏移除品牌）

> **关键决策**：本版本**不涉及业务逻辑变更**，不改路由、不改 Store、不改 Rust 后端。

## 二、架构设计

### 2.1 分层结构

```

  ├── :root 默认变量（半透明背景 + 模糊参数）
  ├── [data-primary='bamboo'] 主色变体

  ├── 重置、滚动条
  ├── 工具类（.tea-glass、.tea-fade-in 等）
  ├── 主题容器（背景层 + 装饰层）
  └── Naive UI 主题适配

Ant Design 覆盖层 (n-overrides.css) ← 新增
  ├── 弹窗（n-modal-content）顶部装饰条 + 模糊遮罩
  ├── 弹窗内输入框下划线风格
  ├── 抽屉（n-drawer）毛玻璃
  ├── 下拉（n-dropdown）毛玻璃
  ├── 消息（n-message）毛玻璃
  ├── 卡片（n-card）毛玻璃
  ├── 表格（n-table）圆角与表头
  ├── 标签/分段/开关/分页 主题适配
  └── 提示/气泡/通知 毛玻璃

登录页模块 (LoginView) ← 新增
  ├── 极光背景层（30s drift 动画）
  ├── 网格装饰层（60px 网格 + mask 中心）
  ├── 噪点层（SVG 噪点 opacity 0.2）
  ├── 发光圆点层（6-10 个 3s 脉冲）
  ├── 渐变登录卡片 + 顶部光带
  ├── Logo 脉冲 + 外环渐显

  ├── 分组标题 + 子项列表

  ├── tea-scale-in 进入动画
  └── 与 dashboard 一致的毛玻璃风格
```

### 2.2 关键设计决策

| 决策点 | 方案 | 理由 |
|--------|------|------|
| 毛玻璃如何应用于深色 | 半透明 + blur 统一变量 | 浅色/深色只是底色不同，模糊参数不变 |
| 内容区背景如何有层次 | 双层：底色 + 装饰 SVG/渐变 | 静态可保性能，视觉有质感 |
| Ant 覆盖写法 | 类名覆盖 + `!important` | 抗 Naive UI 版本更新能力最强 |
| 标题栏品牌移除 | TitleBar.vue 移除 brand div | 用户明确要求；仿 JXC |
| 工作台数据来源 | Mock 占位 + 标注"演示数据" | 当前无后端 API，避免误导 |
| Spring 曲线应用范围 | 仅模态/抽屉/弹窗的进入动画 | 局部使用避免视觉疲劳 |
| Dashboard 是否拆子组件 | 拆为 DashboardHero / QuickActions / TodayStats 三个 .vue | 复用 + 维护性 |

## 九、技术风险

| 风险 | 等级 | 缓解 |
|------|------|------|
| Naive UI 升级后类名变化导致覆盖失效 | 🟡 中 | 用具体类名 + `!important`，不依赖子选择器 |
| 毛玻璃在低性能设备上卡顿 | 🟢 低 | blur 控制在 12-24px，避免过大 |
| 标题栏半透明导致文字对比度不足 | 🟡 中 | 变量中保持文字色 `--tea-titlebar-text` 为深色 |
| 内容区双层背景影响滚动 | 🟢 低 | ::before/::after 用 `position: fixed` 配合 z-index -2/-1 |
| 工作台 mock 数据误导 | 🟡 中 | 标题旁明确标"演示数据" |

### 14.2 逻辑改动

把"折叠态直接激活"改为"折叠态分组按钮 → 打开弹窗"：

```typescript
function handleGroupClick(groupKey: string, groupTitle: string) {
  if (props.collapsed) {
    const el = (event.currentTarget as HTMLElement).getBoundingClientRect()
    popupState.groupTitle = groupTitle
    popupState.items = getMenuItemsByGroup(groupKey)
    popupState.top = el.top
    popupState.left = el.right + 4
    popupState.show = true
  } else {
    // 展开态行为保持
  }
}
```

### 14.3 外部点击关闭

```typescript
import { onMounted, onBeforeUnmount } from 'vue'
function handleDocClick(e: MouseEvent) {
  if (!popupState.show) return
  const target = e.target as HTMLElement
  if (target.closest('.tea-sider-popup')) return
  if (target.closest('.tea-sider-group')) return
  closePopup()
}
onMounted(() => document.addEventListener('mousedown', handleDocClick))
onBeforeUnmount(() => document.removeEventListener('mousedown', handleDocClick))
```
