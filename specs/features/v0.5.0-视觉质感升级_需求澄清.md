# v0.5.0 视觉质感升级 - 需求澄清

> **版本号**：v0.5.0
> **类型**：minor（视觉质感升级：毛玻璃 + 动效细节 + 工作台）
> **前置版本**：v0.4.0
> **创建日期**：2026-07-04

---

## 一、需求来源

参考项目 `D:\AI\AI\JXC`（进销存系统）的 UI 设计经验，针对当前茶易管 v0.4.0 仍有较大视觉差距的现状进行升级迭代。

## 二、核心差距分析

| 维度 | JXC | 茶易管 v0.4.0 | 差距等级 |
|------|-----|---------------|---------|
| 毛玻璃质感 | 全面应用（标题栏/侧栏/卡片/弹窗） | 局部有（仅浮窗） | 🔴 关键 |
| 标签激活态 | 底部 2px 主色指示线 + 背景变色 | 仅有背景变色 | 🟡 重要 |
| 侧栏激活项 | 左侧 3px 发光竖条 + 背景 | 仅有背景 | 🟡 重要 |
| 卡片 hover 抬升 | `translateY(-2px)` + 阴影提升 | 无 | 🟢 锦上添花 |
| 弹窗顶部装饰 | 渐变光带（动画散开） | 无 | 🟢 锦上添花 |
| 弹窗输入框 | 下划线风格（Material） | 完整边框 | 🟢 锦上添花 |
| 工作台欢迎页 | 渐变 Hero + 问候 + 快捷操作 | 空 | 🟡 重要 |
| 品牌位置 | 仅在侧边栏（展开时） | 标题栏 + 侧边栏重复 | 🟡 重要 |
| 标题栏高度 | 52px | 56px | 🟢 微调 |

## 四、验收标准（AC）

### 4.1 毛玻璃视觉升级（AC-A）

**AC-A1**：标题栏背景采用半透明色 + `backdrop-filter: blur(20px) saturate(180%)`，背后内容能透出模糊感
- 给定：当前页面有彩色图片或卡片
- 当：滚动或切换页面时
- 那么：标题栏始终呈现"毛玻璃"效果

**AC-A2**：侧边栏背景采用半透明色 + `backdrop-filter: blur(20px) saturate(180%)`
- 给定：侧边栏悬浮在内容区上方
- 当：内容区滚动时
- 那么：侧边栏背后能看到内容模糊透出

**AC-A3**：所有 n-card / 自定义卡片默认应用毛玻璃（`rgba` + blur）
- 给定：任意业务页面有 NCard 组件
- 当：加载完成时
- 那么：卡片呈现半透明 + 模糊质感

**AC-A4**：深色模式下，毛玻璃效果依然存在但底色调暗
- 给定：主题切换到深色
- 当：所有元素应用对应变量
- 那么：深色下也是半透明模糊，颜色更暗

**AC-A5**：内容区背景支持**两层视觉**（底色 + 装饰）
- 给定：内容区背景
- 当：查看时
- 那么：底层为纯色，上层可叠加淡淡的茶纹/渐变（提升视觉层次）

**AC-J11**：登录按钮 shimmer 动画
- 给定：登录按钮

- 那么：按钮内 3s shimmer 光带扫过（伪元素）

## 六、风险评估

| 风险 | 等级 | 缓解措施 |
|------|------|---------|
| 毛玻璃在低端 GPU 上卡顿 | 🟢 低 | blur(12-20px) 已平衡；提供关闭选项（用户在主题设置） |
| Ant Design 覆盖样式与新版不兼容 | 🟡 中 | 用具体类名覆盖（.n-modal-content）而非通配 |
| 工作台 mock 数据让用户误以为有功能 | 🟡 中 | 明确标注"演示数据" |
| 主色切换导致深色背景下对比度不足 | 🟡 中 | 切换主色时同时调整深色变量变体 |
| 大量 CSS 改动可能引入样式冲突 | 🟡 中 | 增量改 + 每步编译验证 |
