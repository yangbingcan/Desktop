## 一、概述

库存管理是茶叶店管理系统的核心，包括库存查询、入库、出库（FIFO扣减）、防超卖保护、流水记录等功能。

## 二、数据库设计

### 2.1 新增表

#### 库存批次表 (inventory_batches)

```sql
CREATE TABLE inventory_batches (
    id TEXT PRIMARY KEY NOT NULL,
    product_id TEXT NOT NULL,
    batch_code TEXT NOT NULL UNIQUE,
    purchase_price REAL NOT NULL DEFAULT 0,
    total_grams INTEGER NOT NULL DEFAULT 0,
    remaining_grams INTEGER NOT NULL DEFAULT 0,
    supplier_id TEXT,
    produced_date TEXT,
    expire_date TEXT,
    created_at TEXT NOT NULL DEFAULT (datetime('now')),
    FOREIGN KEY (product_id) REFERENCES products(id) ON DELETE CASCADE
);

CREATE INDEX idx_batch_product ON inventory_batches(product_id);
CREATE INDEX idx_batch_code ON inventory_batches(batch_code);
CREATE INDEX idx_batch_remaining ON inventory_batches(remaining_grams);
```

#### 库存流水表 (stock_flow)

```sql
CREATE TABLE stock_flow (
    id TEXT PRIMARY KEY NOT NULL,
    product_id TEXT NOT NULL,
    batch_id TEXT,
    flow_type TEXT NOT NULL CHECK (flow_type IN (
        'purchase_in',   -- 采购入库
        'sale_out',      -- 销售出库
        'damage_out',    -- 报损出库
        'return_out',    -- 退货出库
        'adjust_in',     -- 盘点盘盈
        'adjust_out'     -- 盘点盘亏
    )),
    change_grams INTEGER NOT NULL DEFAULT 0,
    balance_grams INTEGER NOT NULL DEFAULT 0,
    order_id TEXT,
    remark TEXT,
    created_at TEXT NOT NULL DEFAULT (datetime('now')),
    FOREIGN KEY (product_id) REFERENCES products(id) ON DELETE CASCADE,
    FOREIGN KEY (batch_id) REFERENCES inventory_batches(id) ON DELETE SET NULL
);

CREATE INDEX idx_flow_product ON stock_flow(product_id);
CREATE INDEX idx_flow_type ON stock_flow(flow_type);
CREATE INDEX idx_flow_created ON stock_flow(created_at);
```

### 2.2 products 表变更

商品表需要新增库存相关字段：

```sql
ALTER TABLE products ADD COLUMN stock_grams INTEGER NOT NULL DEFAULT 0;
ALTER TABLE products ADD COLUMN stock_units INTEGER NOT NULL DEFAULT 0;
```

### 3.3 数据结构

```rust
/// 库存概览
struct InventoryItem {
    product_id: String,
    product_name: String,
    category_name: String,
    product_type: ProductType,
    stock_grams: i64,
    stock_units: i64,
    // 计算字段：换算显示
    display_stock: String,  // 如 "1件2750g"
}

/// 商品库存详情
struct InventoryDetail {
    product: Product,
    stock_grams: i64,
    stock_units: i64,
    batches: Vec<Batch>,
    recent_flows: Vec<StockFlow>,
}

/// 批次信息
struct Batch {
    id: String,
    batch_code: String,
    purchase_price: f64,
    total_grams: i64,
    remaining_grams: i64,
    supplier_name: Option<String>,
    produced_date: Option<String>,
    expire_date: Option<String>,
    created_at: String,
}

/// 库存流水
struct StockFlow {
    id: String,
    product_id: String,
    batch_id: Option<String>,
    flow_type: String,
    change_grams: i64,
    balance_grams: i64,
    order_id: Option<String>,
    remark: Option<String>,
    created_at: String,
}

/// 采购入库输入
struct PurchaseInput {
    supplier_id: Option<String>,
    handler: Option<String>,
    items: Vec<PurchaseItem>,
    remark: Option<String>,
    pay_status: PayStatus,
}

/// 采购单据
struct PurchaseOrder {
    id: String,
    order_no: String,
    supplier_id: Option<String>,
    handler: Option<String>,
    total_amount: f64,
    pay_status: PayStatus,
    remark: Option<String>,
    items: Vec<PurchaseItem>,
    created_at: String,
}

/// 采购单据明细
struct PurchaseItem {
    product_id: String,
    unit_id: String,
    quantity: i64,
    unit_price: f64,
    grams: i64,        // 换算后的克数
    subtotal: f64,
}

/// 盘点调整输入
struct AdjustInput {
    product_id: String,
    grams: i64,        // 正数盘盈，负数盘亏
    remark: String,
}
```

## 四、核心算法

### 4.1 入库算法

```
1. 开启事务
2. 生成批次号（RK + 年月日 + 序号）
3. 计算实际入库克数 = 数量 × 换算
4. 插入批次记录
5. 更新商品库存（stock_grams += 克数）
6. 记录流水（类型=purchase_in）
7. 提交事务
```

### 4.2 FIFO 出库算法

```
1. 开启排他事务（BEGIN EXCLUSIVE）
2. 检查库存是否充足
3. 扣减商品库存（stock_grams -= 克数）
4. 查询所有批次（remaining_grams > 0），按 created_at 升序
5. 从最早批次开始扣减：
   - remaining -= min(批次剩余, 需扣减)
   - 更新批次剩余
   - 直到扣减完毕
6. 记录流水（类型=sale_out/damage_out/return_out）
7. 提交事务
```

### 4.3 防超卖

```rust
fn check_stock(conn: &Connection, product_id: &str, required_grams: i64) -> Result<bool, String> {
    let stock: i64 = conn.query_row(
        "SELECT stock_grams FROM products WHERE id = ?",
        [product_id],
        |row| row.get(0),
    )?;
    Ok(stock >= required_grams)
}
```

## 八、风险与注意事项

1. **并发安全**：出库操作必须使用 BEGIN EXCLUSIVE 排他事务
2. **FIFO 精度**：批次扣减必须严格按照时间顺序
3. **库存一致性**：每次库存变更后必须记录流水
4. **单位换算**：入库/出库时注意销售单位到基准单位的换算
