> **优先级**：P0
> **依赖模块**：M01-商品档案

## 一、功能概述

库存管理是整个茶叶店管理系统的核心算法层，负责管理商品库存的增减、批次追踪、FIFO扣减和防超卖保护。

### 1.1 核心价值

- **精确计量**：所有库存统一折算为基准单位（克/个）进行计算
- **批次追溯**：每笔入库生成独立批次，支持追溯成本和保质期
- **FIFO扣减**：销售出库按先进先出原则从最早批次扣减
- **防超卖**：数据库行级锁 + 库存校验，防止库存扣成负数

## 二、业务规则

### 2.1 底层存储规则

| 商品类型 | 存储字段 | 单位 |
|---------|---------|------|
| 称重类 | `stock_grams` | 克（整数） |
| 计件类 | `stock_units` | 个（整数） |

### 2.2 入库换算逻辑

```
用户操作：采购入库"牛栏坑肉桂" 2件
↓
系统读取换算关系：1件 = 20罐，1罐 = 250g → 1件 = 5000g
↓
实际入库克数 = 2 × 5000 = 10000g
↓
UPDATE products SET stock_grams = stock_grams + 10000 WHERE id = xxx
↓
同时写入 inventory_batches 表（批次号、入库价、剩余克数）
```

### 2.3 出库（销售/报损）换算逻辑

```
用户操作：零售卖出"牛栏坑肉桂" 半斤（250g）
↓
校验：SELECT stock_grams FROM products WHERE id = xxx → 假设当前 8000g
↓
校验通过（8000 >= 250）
↓
扣减：UPDATE products SET stock_grams = stock_grams - 250
↓
批次扣减：按 FIFO（先进先出）从最早批次的 remaining_grams 中扣除 250g
↓
写入 stock_flow 流水表（类型=销售出库，变更=-250g，结余=7750g）
```

### 2.4 防超卖保护

- 销售下单时加**数据库行级锁**（BEGIN EXCLUSIVE TRANSACTION）
- 防止并发操作导致库存扣成负数
- 若库存不足，前端弹窗提示："当前库存仅剩 X g，是否继续？"

## 六、技术实现要点

### 6.1 库存扣减伪代码

```rust
async fn deduct_inventory(
    conn: &Connection,
    product_id: &str,
    grams: i64,
) -> Result<(), String> {
    // 1. 开启排他事务
    conn.execute("BEGIN EXCLUSIVE TRANSACTION", [])?;

    // 2. 检查库存
    let stock: i64 = conn.query_row(
        "SELECT stock_grams FROM products WHERE id = ?",
        [product_id],
        |row| row.get(0),
    )?;

    if stock < grams {
        conn.execute("ROLLBACK", [])?;
        return Err(format!("库存不足，当前库存 {}g，需要 {}g", stock, grams));
    }

    // 3. 扣减库存
    conn.execute(
        "UPDATE products SET stock_grams = stock_grams - ? WHERE id = ?",
        params![grams, product_id],
    )?;

    // 4. FIFO 批次扣减
    deduct_from_batches(conn, product_id, grams)?;

    // 5. 记录流水
    record_stock_flow(conn, product_id, -grams, "sale_out", None)?;

    // 6. 提交事务
    conn.execute("COMMIT", [])?;

    Ok(())
}
```

### 6.2 FIFO 批次扣减

```rust
fn deduct_from_batches(
    conn: &Connection,
    product_id: &str,
    grams: i64,
) -> Result<(), String> {
    let mut remaining = grams;

    // 查询所有批次，按创建时间排序（先进先出）
    let mut stmt = conn.prepare(
        "SELECT id, remaining_grams FROM inventory_batches
         WHERE product_id = ? AND remaining_grams > 0
         ORDER BY created_at ASC"
    )?;

    let batches = stmt.query_map([product_id], |row| {
        Ok((row.get::<_, String>(0)?, row.get::<_, i64>(1)?))
    })?;

    for batch in batches {
        if remaining <= 0 { break; }

        let (batch_id, batch_remaining) = batch?;

        let deduct = remaining.min(batch_remaining);
        conn.execute(
            "UPDATE inventory_batches SET remaining_grams = remaining_grams - ? WHERE id = ?",
            params![deduct, batch_id],
        )?;

        remaining -= deduct;
    }

    Ok(())
}
```
