## 一、通用规范

### 1.1 文件头注释（强制）

所有源代码文件必须包含文件头注释，说明文件用途。

**Vue/TypeScript 文件：**

```typescript
/**
 * @file 商品状态管理 - 管理商品列表、新增、编辑、删除等状态
 * @description 用于商品模块的 Pinia store，封装商品相关的所有状态和操作
 */
```

**Rust 文件：**

```rust
//! 商品数据模型定义
//! 
//! 包含商品结构体、关联单位换算、批次信息等数据模型

use serde::{Serialize, Deserialize};
```

**SQL 文件：**

```sql
-- 商品表定义
-- 包含商品基础信息、类型、库存基准单位等字段
--
-- @author 开发团队
-- @date 2026-07-01

    ...
);
```

### 1.2 函数/方法注释

```typescript
/**
 * 计算商品价格
 * @param productId 商品ID
```

### 1.3 行内注释

注释解释"为什么"，而不是"做了什么"：

```typescript
// 使用 FIFO 所以按创建时间排序，而不是更新时间
```

### 2.3 Store 规范（Pinia）

**Store 文件：`src/stores/`**

```typescript
// src/stores/products.ts
/**
 * @file 商品状态管理
 */
import { defineStore } from 'pinia'
import { ref, computed } from 'vue'
import { getProducts, createProduct, updateProduct, deleteProduct } from '@/api/products'
import type { Product, SalesUnit } from '@/types'

export const useProductStore = defineStore('products', () => {
    // ========== 状态 ==========
    const products = ref<Product[]>([])
    const loading = ref(false)
    const currentProduct = ref<Product | null>(null)

    // ========== 计算属性 ==========
    const productMap = computed(() => {
        return new Map(products.value.map(p => [p.id, p]))
    })

    const weightProducts = computed(() => {
        return products.value.filter(p => p.type === 'weight')
    })

    // ========== Actions ==========
    async function loadProducts() {
        loading.value = true
        try {
            products.value = await getProducts()
        } finally {
            loading.value = false
        }
    }

    async function addProduct(product: Product) {
        const created = await createProduct(product)
        products.value.push(created)
        return created
    }

    return {
        // 状态
        products,
        loading,
        currentProduct,
        // 计算属性
        productMap,
        weightProducts,
        // 方法
        loadProducts,
        addProduct
    }
})
```

### 3.3 库存核心逻辑（FIFO）

```rust
// src-tauri/src/services/inventory_service.rs
//! 库存服务核心逻辑
//! 
//! 实现库存扣减的 FIFO 算法，确保批次追溯

use rusqlite::Connection;
use crate::models::InventoryBatch;

/// 库存扣减结果
#[derive(Debug)]
pub struct StockDeductionResult {
    pub success: bool,
    pub deducted_grams: i64,
    pub remaining_stock: i64,
    pub batch_details: Vec<BatchDeduction>,
}

/// 批次扣减详情
#[derive(Debug)]
pub struct BatchDeduction {
    pub batch_id: String,
    pub deducted_grams: i64,
    pub remaining_grams: i64,
}

/// 按 FIFO 规则扣减库存
/// 
/// 核心规则：
/// 1. 按批次创建时间先进先出
/// 2. 先扣除最早批次的库存
/// 3. 一个批次扣完再扣下一个批次
/// 4. 记录每个批次的扣减明细
/// 
/// # Arguments
/// * `conn` - 数据库连接
/// * `product_id` - 商品ID
/// * ` grams` - 需要扣除的克数
/// 
/// # Returns
/// * `StockDeductionResult` - 扣减结果
pub fn deduct_stock_fifo(
    conn: &Connection,
    product_id: &str,
    grams: i64
) -> Result<StockDeductionResult, String> {
    // 1. 查询当前库存
    let current_stock: i64 = conn.query_row(
        "SELECT stock_grams FROM products WHERE id = ?",
        [product_id],
        |row| row.get(0)
    ).map_err(|e| e.to_string())?;

    // 2. 检查库存是否充足
    if current_stock < grams {
        return Err(format!(
            "库存不足：当前库存 {}g，需要 {}g",
            current_stock, grams
        ));
    }

    // 3. 获取所有批次（按创建时间升序 = FIFO）
    let mut stmt = conn.prepare(
        "SELECT id, remaining_grams FROM inventory_batches 
         WHERE product_id = ? AND remaining_grams > 0 
         ORDER BY created_at ASC"
    ).map_err(|e| e.to_string())?;

    let batches: Vec<InventoryBatch> = stmt.query_map([product_id], |row| {
        Ok(InventoryBatch {
            id: row.get(0)?,
            remaining_grams: row.get(1)?,
            ..Default::default()
        })
    }).map_err(|e| e.to_string())?
    .filter_map(|r| r.ok())
    .collect();

    // 4. 执行 FIFO 扣减
    let mut remaining_to_deduct = grams;
    let mut batch_details = Vec::new();
    
    for mut batch in batches {
        if remaining_to_deduct <= 0 {
            break;
        }
        
        let deducted = remaining_to_deduct.min(batch.remaining_grams);
        batch.remaining_grams -= deducted;
        remaining_to_deduct -= deducted;
        
        batch_details.push(BatchDeduction {
            batch_id: batch.id.clone(),
            deducted_grams: deducted,
            remaining_grams: batch.remaining_grams,
        });
        
        // 更新批次剩余数量
        conn.execute(
            "UPDATE inventory_batches SET remaining_grams = ? WHERE id = ?",
            rusqlite::params![batch.remaining_grams, batch.id]
        ).map_err(|e| e.to_string())?;
    }

    // 5. 更新商品库存
    let new_stock = current_stock - grams;
    conn.execute(
        "UPDATE products SET stock_grams = ? WHERE id = ?",
        rusqlite::params![new_stock, product_id]
    ).map_err(|e| e.to_string())?;

    Ok(StockDeductionResult {
        success: true,
        deducted_grams: grams,
        remaining_stock: new_stock,
        batch_details,
    })
}
```

## 四、Git 提交规范

### 4.1 提交信息格式

```
<类型>(<范围>): <简短描述>

[可选的正文]

[可选的页脚]
```

### 4.2 类型标识

| 类型 | 说明 |
|------|------|
| `feat` | 新功能 |
| `fix` | BUG 修复 |
| `docs` | 文档更新 |
| `style` | 代码格式（不影响功能） |
| `refactor` | 重构（不是新功能也不是修复） |
| `perf` | 性能优化 |
| `test` | 测试相关 |
| `chore` | 构建/工具相关 |

## 五、数据库规范

### 5.1 表命名

- 表名单数、全小写、下划线分隔：`products`、`inventory_batches`
- 避免复数（`product` 而非 `products`），但保留行业习惯（如 `members`）

### 5.2 字段命名

| 类型 | 规范 | 示例 |
|------|------|------|
| 普通字段 | snake_case | `product_name`、`created_at` |
| 外键 | `<表名>_id` | `product_id`、`member_id` |
| 时间戳 | `_at` | `created_at`、`updated_at` |
| 布尔值 | `is_` / `has_` / `can_` | `is_active`、`has_stock` |

### 5.3 索引规范

- 主键：`PRIMARY KEY (id)`
- 外键索引：自动创建
- 查询条件字段：需要创建索引

```sql
-- 库存流水表索引
CREATE INDEX idx_stock_flow_product_id ON stock_flow(product_id);
CREATE INDEX idx_stock_flow_created_at ON stock_flow(created_at);
CREATE INDEX idx_stock_flow_type ON stock_flow(flow_type);
```

## 六、样式规范

### 6.1 UnoCSS 原子化

优先使用 UnoCSS 原子类，减少自定义 CSS：

```vue
<div class="flex items-center justify-between p-4 bg-white rounded-lg shadow">
    <span class="text-lg font-medium text-gray-800">{{ title }}</span>
    <n-button type="primary" size="small">操作</n-button>
</div>
```

### 6.2 组件样式作用域

```vue
<style scoped>
/* 使用 :deep() 穿透子组件样式 */
:deep(.n-button) {
    margin-right: 8px;
}

/* 避免使用 !important */
.card {
    padding: 16px; /* OK */
}
</style>
```
