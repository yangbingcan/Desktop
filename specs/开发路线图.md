## 一、项目概览

| 项目 | 内容 |
|------|------|
| 项目名称 | 茶易管（TeaManage） |
| 项目类型 | 桌面端应用（Windows/macOS） |
| 技术栈 | Vue 3 + Vite 5 + Naive UI + UnoCSS + Pinia + Tauri 2.x + Rust + SQLite |
| 目标用户 | 中小型茶叶零售店、茶庄、茶空间 |
| 核心价值 | 轻量（<10MB）、稳定、贴合茶叶行业特殊需求（多单位/散茶/口味偏好） |

### 3.2 已完成模块详情

#### ✅ v0.1.0 MVP（已发布）

- M1 商品档案：CRUD、分类（11 个茶叶分类初始化）、多单位、销售/会员价
- M2 库存管理：FIFO 批次扣减、库存流水、库存查询、报损、盘点
- M3 简单收银：商品录入、会员识别、挂单/取单、结算、积分

#### ✅ v0.2.0 V1.0 闭环（已发布）

- M4 出入库闭环：供应商档案、退货出库、采购入库单供应商必填
- M5 会员管理：会员 CRUD、口味偏好、消费记录、积分升级
- 数据库：SCHEMA_VERSION 升级到 2（suppliers / return_orders / return_items）
- 验收：14/17 通过（3 项遗留：AC-P-02/03 推迟 v0.3.0）

#### ✅ v0.6.0 ~ v0.6.2（已发布）

- v0.6.0：全站 UI 设计系统统一（深茶绿主题规范 + mdi 图标 + 布局/文字/金额规范，29 文件）。
- v0.6.1：代码全面检查修复（路由鉴权门禁 + 金额边界四舍五入 + 生产清空命令门禁 + UI 收敛 + 死依赖清理）。
- v0.6.2（M08 打印模板设计器）：
  - M6 打印模板 100%：小票/采购/退货/条码标签 4 类模板，结构化区块配置器（开关/字号/对齐/标题/字段/自定义文本/纸张），实时预览，localStorage 持久化。
  - 标签打印含 Code128 一维码 + 二维码（jsbarcode / qrcode 动态生成）；打印通道复用浏览器 `window.print()`。
  - M3 小票、M4 采购/退货详情页均已接入模板引擎真实打印。
  - 无数据库变更（模板存 localStorage），依版本规则取 patch。

## 四、v0.3.0 里程碑规划（核心）

### 4.1 目标

**让系统具备"日常营业级"完整可用性**：
- 采购入库能查询历史单据（数据闭环）
- 会员能充值和扣款（增强会员粘性）
- 小票能真实打印（替代占位 UI）
- 代码质量有测试保障（降低维护成本）

## 八、风险与应对
