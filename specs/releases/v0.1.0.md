## 技术决策

| 决策 | 选型 | 理由 |
|------|------|------|
| 桌面壳 | Tauri 2.x | 安装包 < 10MB、内存低、原生后端 |
| 前端框架 | Vue 3.4+ + Vite 5 | 上手快、生态成熟、热更新秒级 |
| UI 库 | Naive UI | TS 体验好、Tree-shaking、暗色模式 |
| 样式引擎 | UnoCSS | 比 Tailwind 更快更小 |
| 后端语言 | Rust | 类型安全、事务逻辑可靠、零运行时 |
| 数据库 | SQLite (rusqlite) | 单文件、ACID、适合单机 |
| 事务策略 | `BEGIN EXCLUSIVE TRANSACTION` | 销售/出库全流程原子性 |
