## 一、版本概述

v0.6.2 落地 **M08 打印模板设计器**，把此前写死在 `utils/print.ts` 的小票/采购单 HTML 重构为「结构化区块模板 + 渲染引擎」驱动的可视化设计器。满足用户对打印的核心诉求：**先做界面与模板设计，真实打印经由浏览器 `window.print()`（暂不引入 ESC/POS 原生驱动）**。

交付能力：
1. **4 类模板**：零售小票（receipt）、采购入库单（purchase）、退货出库单（return）、条码标签（label）。
2. **结构化区块配置器**（非拖拽、非裸 HTML）：每类模板由 `header / shopInfo / meta / items / summary / member / customText / barcode / qrcode` 区块组成，可逐块开关、调字号、对齐、改标题/字段/自定义文本、设纸张尺寸，实时预览。
3. **真实打印**：`window.print()`（iframe 注入）复用既有打印通道；标签含 Code128 一维码 + 二维码（jsbarcode / qrcode 动态生成 dataURL）。
4. **持久化**：模板存 `localStorage`（键 `tea-print-templates`），配套 Pinia store 与种子模板，不改动任何后端命令与数据库 schema。
5. **集成接入**：采购详情页「打印采购单」、退货详情页「打印退货单」、条码管理「标签设计」预览/打印、收银台结算后小票打印（已接入）。

### 1.1 是否涉及数据库变更

**否**。模板数据存 `localStorage`，渲染引擎为纯前端 TS，后端 Rust 命令与 SQLite schema 零改动。因此按项目版本规则「无 DB 变更 → patch 递增」（0.6.1 → 0.6.2）。

> 注：M08 技术方案原规划 v0.7.0（minor），但因本次无数据库变更，依版本铁律取 patch。如后续需并入其他 minor 特性可再评估。

## 三、核心变更

### 3.1 渲染引擎与数据模型

- 模板由「区块数组」描述，每个区块含 `kind / enabled / fontSize / align / fields? / title? / text?`。
- 小票/采购/退货走 `renderTemplateHTML`（同步字符串拼接）；标签走 `renderLabelHTML`（异步，用离屏 canvas 生成条码/二维码 dataURL）。
- 渲染数据单一来源：店铺信息取自 `settings` store；单据数据由 `SaleOrder / PurchaseOrder / ReturnOrder` 映射（见 `print.ts` 的 `toReceiptData` 等）。
- 4 类单据均提供种子模板；首启动或 localStorage 无数据时回退种子，避免空白。

### 3.2 结构化区块配置器（UI）

- `TemplateDesigner.vue` 不暴露裸 HTML，仅以开关/下拉/输入框配置区块，杜绝用户写错标签导致打印崩。
- `TemplatePreview.vue` 用 iframe `srcdoc` 隔离样式，所见即所得；标签模板因需异步生成图片，预览组件内部 `await renderLabelHTML` 后注入。
- 纸张尺寸（`widthMm` / `heightMm`）驱动 `@page` 打印规格（小票 58mm、单据 A4、标签 40×30mm 等）。

### 3.3 打印通道与集成

- `print.ts` 的 `printHTML` 维持既有 iframe + `window.print()` 通道；`printReceipt` 优先用模板，异常回退旧写死 HTML（向后兼容）。
- 采购/退货详情页、条码标签「打印」按钮均接模板引擎；收银台小票打印已在 v0.6.1 前接入 `printReceipt`，本次自动受益。

### 3.4 关键技术约束（esbuild 模板字符串解析缺陷）

- 发现 esbuild 对模板字符串中 `">${变量}`（属性闭合引号紧跟变量插值）会误报 `Unterminated string literal`。
- 规避方式：渲染器统一用 `divBlock(style, innerHtml)` 辅助函数做字符串拼接，使 `">` 落在字面量末尾，彻底规避。单测覆盖保证不回退。

## 六、风险评估

### 6.1 高风险项

无。

### 6.2 中风险项

1. **打印依赖浏览器 `window.print()`**
   - 影响：走系统打印对话框，未直接驱动 ESC/POS 热敏打印机；58mm 小票样式依赖打印机/纸张设置。
   - 缓解：用户本阶段明确「先做界面与模板设计，真实打印走浏览器」，原生 ESC/POS 驱动作为后续独立需求。

2. **条码/批次查询仍为占位**
   - 影响：条码管理页「零售条码 / 批次追溯」查询为 message 提示，标签「打印」当前用演示数据。
   - 缓解：标签版式由打印模板设计器驱动，查询能力属 M7 独立范围，不阻塞本版本。

### 6.3 低风险项

- esbuild 解析怪癖已通过 `divBlock` 规避并单测覆盖，后续新增区块渲染函数须沿用同一模式。
