## 一、版本概述

v0.3.6 重点完善供应商财务管理和出入库编辑功能：

1. **出入库单编辑** — 采购入库单和退货出库单现在支持编辑（日期、商品明细）
2. **付款管理** — 新增供应商付款记录表，采购单支持分次付款，自动更新付款状态
3. **供应商详情升级** — 抽屉改为 Tab 布局：基本信息 / 入库单 / 退货单 / 付款记录 / 财务流水，顶部显示欠款余额
4. **数据库迁移** — v6：新增 `supplier_payments` 表

## 三、变更描述

### 3.1 出入库单编辑

- **采购单编辑**：在采购单列表操作列新增「编辑」按钮，跳转到 `/purchase/:id/edit`，可修改日期和商品明细。更新逻辑：事务内先还原旧库存（删除批次、扣减库存），再用新数据重新创建
- **退货单编辑**：同理，`/returns/:id/edit`，先还原旧库存再重新创建
- 更新后单据的 ID 和单号保持不变

### 3.2 付款管理

- **新建 `supplier_payments` 表**：记录每笔付款的供应商、关联采购单、金额、方式、日期
- **采购单付款**：在采购单详情抽屉底部点击「付款」，录入金额/方式/日期，支持分次付款
- **自动更新付款状态**：付款后自动计算采购单已付总额，更新 `payment_status`（unpaid/partial/paid）
- **供应商欠款计算**：欠款 = 采购总额 - 已付总额 - 退货冲抵

### 3.3 供应商详情升级

- 抽屉宽度 520 → 640，顶部显示供应商名称 + 欠款余额概览
- 5 个 Tab：
  - 基本信息（原内容）
  - 入库单：该供应商的采购入库记录
  - 退货单：该供应商的退货出库记录
  - 付款记录：该供应商的付款历史
  - 财务流水：合并展示采购/退货/付款的完整流水
