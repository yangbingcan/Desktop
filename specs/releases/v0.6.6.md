# 茶易管 v0.6.6 版本说明

- **版本**：0.6.6（patch，无数据库结构变更）
- **日期**：2026-07-15
- **类型**：代码全面审查修复 + 业务一致性补全

## 新增与调整

### 1. 修复数据一致性致命缺陷（CR-01）
- 销售 / 退货对**计件类**商品原恒操作 `stock_grams`，忽略 `product_type`，导致计件商品库存账目永久错乱。
- 改为按类型选择库存列（`CASE WHEN product_type='weight' THEN stock_grams ELSE stock_units END`），库存检查 / 扣减 / 流水余额三处一致。

### 2. 库存 / 采购输入校验（S-1 / S-2）
- `damage_out` 报损数量 ≤ 0 时回滚并提示，杜绝负数增库存。
- `purchase_in` 校验单价非负、数量 > 0。

### 3. 订单号并发冲突（IM-02）
- 销售 / 退货订单号追加 4 位随机后缀，避免同一毫秒内并发生成重复单号。

### 4. 前端业务补全
- 采购单补传 `paymentStatus`（C4），修复付款状态恒为默认 unpaid 且修正其 TypeScript 联合类型。
- 新增会员：保存偏好（C5），偏好选项 `v-for` 遍历 API 中文常量，修正原硬编码拼音值错配（C6）。
- 会员折扣标签改为基于等级动态计算（I1）。
- 会员折扣尊重系统「启用会员折扣」开关（C2）：后端新增 `apply_member_discount` 入参作为唯一来源，前端折扣计算与提交均一致。

### 5. 系统设置持久化与初始化（I2 / I3）
- 设置改为 localStorage 持久化，刷新 / 重启后不丢失（I2）。
- 「初始化数据库」按钮接入 `seed_demo_data`（清空 + 演示数据），并增加 danger 二次确认弹窗（I3）。
