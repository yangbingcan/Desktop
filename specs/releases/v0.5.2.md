## 一、版本概述

v0.5.2 是 v0.5.1 之后的**主题适配补丁**，解决用户在 v0.5.1 上反馈的 5 类问题：

1. **图标绿色字体/绿色背景** — Naive UI 未注入 darkTheme，导致亮色主题色调贯穿深色模式；success 颜色过亮
2. **页面和系统不够紧凑** — 表格/列表/卡片空白过多，每屏展示数据密度低
3. **深色模式下仍为白色** — Naive UI 组件不知道当前是深色模式，仍使用浅色主题
4. **侧边栏分组虚线错位** — 树状连线位置与菜单图标重叠，激活态竖条位置偏差
5. **首页 dashboard 深色模式混乱** — 卡片背景色/边框色/文字色在深色模式下不统一

### 1.1 核心修复

- **Naive UI 主题注入** — App.vue 的 `n-config-provider` 引入 `darkTheme`，跟随 themeStore 切换
- **强调色去刺眼化** — success/warning/danger/info 从 Ant Design 默认亮色（#52C41A/#FA8C16/#FF4D4F/#1677FF）调整为茶主题柔色（#5B8C5A/#C97A2B/#C25A60/#3D7AB8）
- **侧边栏虚线精确定位** — 树状连线 left 从 16px 改为 20px（对齐菜单图标中心），top/bottom 重新计算
- **紧凑化覆盖** — 按钮/输入框/标签/分页/描述列表/弹窗/抽屉全部压缩 padding 和高度
- **兜底白名单** — globals.css 中 `[style*='color: #fff']` 等规则新增 DashboardHero 排除白名单，避免误改渐变背景上的白字

### 1.2 设计理念

> **核心原则**：建立语义化颜色 token 体系 + Naive UI 主题动态注入 + 全面深色适配 + 紧凑化数据密度
> **范围限定**：**不改业务逻辑、不改路由、不改 Store、不改后端、不改组件结构**
> **兼容性**：v0.5.0 / v0.5.1 的所有功能 100% 保留

## 三、核心变更

### 3.1 语义化颜色 token 体系

新增 5 大类共 30+ 个语义化 CSS 变量，所有深色模式适配都基于这套 token 体系：

#### Surface（背景层）

```css
/* 浅色模式 */
--tea-surface-1: #FAF6F1;        /* 页面级背景 */
--tea-surface-2: #FFFFFF;        /* 卡片背景 */
--tea-surface-3: #F7F4F0;        /* 嵌套卡片/行背景 */
--tea-surface-hover: #F7E5D4;    /* hover 背景 */
--tea-surface-active: #FBF2E8;   /* 选中/激活背景 */
--tea-surface-overlay: rgba(255, 255, 255, 0.72);
--tea-surface-mask: rgba(0, 0, 0, 0.04);

/* 深色模式 */
--tea-surface-1: #14100C;
--tea-surface-2: #1F1812;
--tea-surface-3: #251D16;
--tea-surface-hover: rgba(196, 149, 106, 0.12);
--tea-surface-active: rgba(196, 149, 106, 0.18);
--tea-surface-overlay: rgba(31, 24, 18, 0.78);
```

#### Content（文字层）

```css
/* 浅色模式 */
--tea-content-1: #5B4636;        /* 标题（最深） */
--tea-content-2: #6B5B4B;        /* 正文 */

--tea-content-5: #C4B8A8;        /* 极弱/禁用 */
--tea-content-inverse: #FFFFFF;  /* 反色（深色按钮文字） */
--tea-content-success: #6B9E78;  /* 成功（柔绿） */
--tea-content-warning: #C9823A;  /* 警告（柔橙） */
--tea-content-danger: #D4838A;   /* 危险（柔红） */

/* 深色模式 - 反转 */

--tea-content-3: rgba(232, 217, 197, 0.65);
```

### 3.2 语义化文字色工具类

替换所有 `text-green-600` / `text-red-600` / `text-gray-500` 等 Tailwind 硬编码颜色类：

```css
.text-primary { color: var(--tea-primary) !important; }
.text-success { color: var(--tea-content-success) !important; font-weight: 600; }
.text-danger  { color: var(--tea-content-danger) !important; font-weight: 600; }
.text-warning { color: var(--tea-content-warning) !important; font-weight: 600; }
.text-light   { color: var(--tea-content-3) !important; }
.text-muted   { color: var(--tea-content-4) !important; }
.text-disabled { color: var(--tea-content-5) !important; }
```

## 四、关键修复示例

### 4.1 销售页空购物车图标（硬编码 → 主题变量）

**修改前**：

```vue
<n-icon :size="40" color="#D4C4B0"><CartOutline /></n-icon>
```

**修改后**：

```vue
<n-icon :size="40" :color="cartEmptyIconColor"><CartOutline /></n-icon>

<script setup>
const cartEmptyIconColor = computed(() => 'var(--tea-content-5)')
</script>
```

### 4.2 会员详情页储值金额（Tailwind 类 → 语义类）

**修改前**：

```vue
<span class="text-orange-500 font-bold">¥{{ balance.toFixed(2) }}</span>
```

**修改后**：

```vue
<span class="text-warning">¥{{ balance.toFixed(2) }}</span>
```

### 4.3 会员储值流水（条件类 → 语义类）

**修改前**：

```vue
class: row.changeAmount > 0 ? 'text-green-600 font-bold' : 'text-red-600 font-bold'
```

**修改后**：

```vue
class: row.changeAmount > 0 ? 'text-success' : 'text-danger'
```

### 4.4 登录按钮（硬编码 white → 主题变量）

**修改前**：

```css
.tea-login-btn {
  background: linear-gradient(135deg, var(--tea-primary) 0%, var(--tea-primary-hover) 100%);
  color: white;
}
```

**修改后**：

```css
.tea-login-btn {
  background: linear-gradient(135deg, var(--tea-primary) 0%, var(--tea-primary-hover) 100%);
  color: var(--tea-content-inverse);
}
```

### 4.5 仪表盘统计卡（硬编码 hex → 主题变量）

**修改前**：

```ts
{ color: '#52C41A', bgColor: 'rgba(82, 196, 26, 0.12)' }
```

**修改后**：

```ts
{ color: 'var(--tea-accent-emerald)', bgColor: 'var(--tea-accent-emerald-bg)' }
```
