## 一、版本概述

v0.5.1 是 v0.5.0 视觉升级的**补齐版本**，包含两部分内容：

### 1.1 仿 JXC 视觉补齐（2 项）

1. **侧边栏树状分组连线** — 展开态 3 个分组内子项左边各显示 1px dashed 主色竖线（仿 JXC gl-sidebar-group-line）

### 1.2 用户反馈 UI/UX 修复（7 项）

| 问题 | 修复 |
|------|------|
| 折叠态侧栏显示"斜杠"虚线方块 | 用真实分组图标（AppsOutline 等）替代 CSS 伪元素 |

| Vue warn: Component that was made reactive | 全局 markRaw（侧栏/TodayStats/QuickActions/Login/UserMenu/路由 Component） |
| Vue warn: <Transition> renders non-element root | router-view 改为 markRaw(Component) + v-if |

### 1.4 决策记录

| 决策 | 选择 | 理由 |
|------|------|------|
| 侧边栏树状连线范围 | 展开态显示 / 折叠态隐藏 | 折叠后无子项列表，连线无意义 |
| 侧边栏树状连线样式 | 1px dashed 主色 + 透明度 0.3 | 仿 JXC，不喧宾夺主 |
| 登录页光斑数量 | 10 → 15 | 用户明确要求 |
| 登录页主题切换 | 卡片右上角圆形按钮 | 极简轻量，不干扰主流程 |
| 记住密码 | localStorage + base64 编码 | 本地防明文，非加密（提示性） |
| 上次用户名 | 始终回填（与是否记住密码无关） | 仿 JXC 主流方案 |
| 密码回填条件 | 仅当记住密码勾选时 | 不勾选则清空密码但保留用户名 |
| 折叠态侧栏分组占位 | 用真实 groupIcon 组件替代 CSS ::after | 24×24 虚线方块易被误认为"斜杠图标" |
| 折叠态弹窗遮罩定位 | left: var(--tea-sider-collapsed) | 避免 mask 挡住侧栏组按钮，导致无法 toggle |
| icon 响应式处理 | 全局 markRaw（数据数组 + 三元 + 路由 Component） | Vue 3.5+ 仍会警告，需显式 markRaw |
| router-view 模板 | `<component :is="markRaw(Component)" v-if="Component" />` | slot 拿到的 Component 会被 Proxy 包裹，导致 Transition 警告 |

## 三、变更描述

### 3.1 侧边栏树状分组连线

#### 视觉规格

- **位置**：展开态 `.tea-sider-group` 内子项列表左侧
- **样式**：`1px dashed var(--tea-primary)` + `opacity: 0.3`
- **范围**：`left: 16px` / `top: 30px` / `bottom: 4px`
- **深色模式**：`opacity: 0.45`（提高对比度）
- **折叠态**：自动隐藏（通过 `:not(.tea-sider-collapsed)` 选择器）

#### 实现原理

使用 CSS 伪元素 `::after` 绝对定位到 `.tea-sider-group` 容器内，无需新增 DOM 节点。

```css
/* 展开态：分组容器相对定位 */
.tea-sider:not(.tea-sider-collapsed) .tea-sider-group {
  position: relative;
}

/* 展开态：分组子项列表左侧 dashed 竖线 */
.tea-sider:not(.tea-sider-collapsed) .tea-sider-group::after {
  content: '';
  position: absolute;
  left: 16px;
  top: 30px;
  bottom: 4px;
  width: 1px;
  border-left: 1px dashed var(--tea-primary);
  opacity: 0.3;
  pointer-events: none;
  z-index: 0;
  transition: opacity var(--tea-transition-normal),
              border-color var(--tea-transition-normal);
}

/* 深色模式适配 */
[data-theme='dark'] .tea-sider:not(.tea-sider-collapsed) .tea-sider-group::after {
  opacity: 0.45;
}
```

#### 风险检查

- ✅ 不与现有 `.tea-sider-group-has-active::before` 冲突（active 竖条在 `.tea-sider-section` 上，新竖线在 `.tea-sider-group` 上）
- ✅ 不与折叠态 `.tea-sider-group::after` 冲突（折叠态用 `.tea-sider-collapsed` 选择器，新规则用 `.tea-sider:not(.tea-sider-collapsed)` 排除）

#### 3.2.3 记住密码 + 上次用户名

**localStorage 键定义**：

| 键 | 值 | 用途 |
|----|----|------|
| `tea-last-username` | 任意字符串 | 上次登录的用户名（始终保存） |

**onMounted 改造**：

```typescript
onMounted(() => {
  // 从 localStorage 恢复登录信息
  const saved = loadRememberedLogin()
  if (saved.username) {
    form.value.username = saved.username
    if (saved.remember && saved.password) {
      form.value.password = saved.password
      rememberPassword.value = true
    }
  } else {
    // 首次进入填充演示账号

```

**handleLogin 改造**：

```typescript
async function handleLogin() {
  if (loading.value) return
  loading.value = true
  // 保存登录信息到 localStorage
  saveRememberedLogin(form.value.username, form.value.password, rememberPassword.value)
  setTimeout(() => {
    loading.value = false
    router.push('/')
  }, 400)
}
```

**安全说明**：
- base64 仅用于本地防明文展示，**非加密**
- 真实场景应使用加密 + 后端校验
- 本地单机版 UI 壳占位，安全等级 = 演示级
