## 一、版本概述

v0.4.0 是一次**纯前端 UI 框架升级**，不影响业务逻辑与数据库：

1. **多标签页系统** — 仿 JXC 浏览器式标签栏，支持多任务并行
2. **侧边栏重构** — 分组、搜索、折叠弹窗，解决 12 个菜单平铺的导航负担
3. **完整主题系统** — 3 主色（茶金/竹青/朱砂）× 2 模式（深/浅），CSS 变量驱动 + localStorage 持久化
4. **融合式标题栏** — 标签栏与品牌区一体化，去除"上下拼凑感"
5. **茶易管风格升级** — 保留中式茶文化调性（深棕+暖金），新增毛玻璃质感与丝滑过渡

### 1.1 设计理念
> **参考项目**：D:\AI\AI\JXC（进销存系统）
> **核心原则**：在 JXC 多标签 + 主题系统基础上，融入茶易管的中式美学

## 三、变更描述

### 3.1 多标签页系统（核心新增）

#### 数据模型
```typescript
interface Tab {
  key: string         // 路由 path
  title: string       // 标签显示名
  closable: boolean   // 是否可关闭（首页 false）
  pin?: boolean       // 是否置顶
}
```

#### 支持的操作
- **打开**：侧栏菜单点击 → `addTab` + `navigate`
- **激活**：点击标签 → `setActiveKey` + `navigate`
- **关闭**：
  - 单点 X 按钮
  - 双击标签
  - 右键菜单：关闭其他 / 关闭所有 / 关闭左边 / 关闭右边
- **拖拽排序**：HTML5 Drag & Drop
- **持久化**：localStorage key=`tea-tabs`
- **首页不可关闭**：`closable=false` 保护

#### 路由↔标签同步
用 `isUpdatingRef` ref 防止两个 useEffect 互相触发死循环（仿 JXC 模式）

#### 标签栏视觉
- 未激活：透明背景 + 二级文字色
- 激活：金色渐变 + 茶色背景 + 底部装饰线
- 关闭按钮：hover 变红
- 溢出：左右渐变遮罩 + 滚轮横向滚动 + 左右按钮

### 3.2 侧边栏重构

#### 分组
| 分组 | 菜单项 |
|------|--------|
| **工作台** | 首页 |
| **业务管理** | 商品档案、库存管理、采购入库、零售收银、会员管理、供应商管理、退货出库 |
| **系统设置** | 打印模板、条码管理、系统设置 |

#### 搜索
顶部输入框，跨分组扁平过滤菜单项，实时显示

#### 折叠弹窗（仿 JXC）
侧边栏折叠时点击分组 → 不展开（无空间），而是从分组右侧**浮出毛玻璃弹窗菜单**

#### 修复原问题
- 移除 `menuKeyToRoute` 硬编码：菜单项直接绑定 `path`
- 移除 activeKey 路由监听器（标签栏已承担激活态管理）
- 移除面包屑（标签栏已承担路径显示）

### 3.3 完整主题系统

#### 主色（3 选 1）
| 名称 | HEX | 风格 |
|------|-----|------|
| 茶金 | `#C4956A` | 经典暖色（默认） |
| 竹青 | `#5B8C5A` | 清雅绿调 |
| 朱砂 | `#B5483F` | 沉稳红调 |

每个主色含：hover / active / light（浅色背景） / bg（更深浅背景） / lightDark / bgDark 共 6 个变体

#### 主题模式
- 浅色（默认）
- 深色

#### 排版
- 字号：小（12px）/ 标准（14px，默认）/ 大（16px）
- 圆角：锐利（4px）/ 圆润（8px，默认）/ 饱满（14px）

#### 布局
- 密度：舒适（默认）/ 紧凑
- 侧栏宽度：紧凑（180px）/ 标准（220px，默认）/ 宽敞（260px）

#### 辅助
- 护眼模式：关闭 / 轻柔 / 适中 / 强效（filter 实现）
- 暖色温：开关（sepia filter）

#### 持久化
- `tea-theme`：主题模式
- `tea-ui-settings`：UI 设置对象
- 加载时自动 apply 到 `document.documentElement.style`

### 3.4 融合式标题栏

**原方案**：左侧侧边栏独立品牌区 + 顶部白底 header
**新方案**：标题栏 56px 高度（与侧边栏同色系），从左到右：
- 品牌 logo + 应用名
- 侧栏折叠按钮
- **多标签页栏**（占满中间）
- 主题切换、设置、用户菜单
- Tauri 窗口控制预留位

**视觉**：标题栏与侧边栏使用**同色系渐变**，侧边栏顶边与标题栏左端对齐，整窗"一块板"。

### 3.5 茶易管风格保留

- 品牌色：保留 `#C4956A` 茶金作为默认
- 字体：`Noto Serif SC` 用于品牌名，中文优雅
- 装饰元素：标题栏底边加 1px `rgba(196, 149, 106, 0.3)` 暖色边
- 标签栏激活态：用茶金渐变 `linear-gradient(135deg, #C4956A, #A87B52)`

## 四、关键设计决策

| 决策点 | 选择 | 理由 |
|--------|------|------|
| 多标签还是单页面 | 多标签 | 用户明确要求；JXC 验证可行 |
| 首页是否可关闭 | 不可关闭 | 仿 JXC；保留工作台作为永驻入口 |
| 主题切换范围 | 3 主色 × 2 模式 | 用户明确要求"完整主题切换" |
| 是否改 Rust 后端 | 不改 | 纯前端 UI 升级，不动数据层 |
| 旧面包屑/时钟 | 删除 | 标签栏已承担路径，时钟非业务必要 |
| 菜单搜索 | 加 | 12 个菜单翻找费时 |
| 侧栏折叠弹窗 | 做 | 仿 JXC，折叠时不浪费空间 |
