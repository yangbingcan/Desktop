## 一、版本概述

v0.6.0 是 v0.5.5 之后的**全站 UI 设计系统统一里程碑**：将此前各页面零散的视觉风格、图标方案、布局写法，统一收敛为一套由 `variables.css` + `App.vue themeOverrides` 全局驱动的深茶绿设计规范。

本次共重构 **29 个文件**（布局外壳 6 + 业务页面 23），达成：

1. **图标体系统一** — 全部图标改用 UnoCSS `mdi` 图标（`i-mdi-leaf` / `i-mdi-tea` / `i-mdi-plus` / `i-mdi-magnify` 等），彻底移除 `@vicons/ionicons5` 依赖与 `i-ic-*` 图标；侧边栏菜单配置 `sidebarMenus.ts` 改为 mdi 类名字符串
2. **根节点规范** — 所有业务页面根节点统一 `tea-page p-md`（`p-md` 在 uno.config 定义 `px-4 py-3`）
3. **布局组件化** — 功能区统一用 `<n-card>` 包裹；间距优先 `<n-space>` / `<n-grid>`，禁止散落 `mt-*`/`mb-*`（1px 边框微调除外）
4. **彩色文字规范** — 走 `<n-text :type>` / `:depth>`，自动适配深浅主题，禁止手写 `style="color:..."` span
5. **金额展示规范** — 金额保留两位小数 + `font-mono` 等宽字体
6. **状态可视化** — 低库存变色（称重类 <500g 预警、计件类 <20 个预警、归零 error）；空状态统一文案「暂无茶叶数据」「今日尚未开单」
7. **字体纪律** — 全局禁止衬线（Serif），使用 PingFang SC / Microsoft YaHei

### 1.1 设计理念

> **核心原则**：
> 1. 通过全局 `themeOverrides` + `variables.css` 单点驱动主题，避免逐页硬编码颜色
> 2. 通过 UnoCSS `mdi` 图标体系消除第三方图标库依赖
> 3. 通过 `n-card` / `n-space` / `n-text` 等 Naive UI 原语约束布局与文字，保证一致性
> 4. 通过 `tea-page p-md` 根节点约定统一页面留白基线
>
> **范围限定**：**不改业务逻辑、不改路由、不改 Store 数据流、不改后端**；纯视觉/标记层重构。
> **兼容性**：v0.5.5 全部功能 100% 保留（纯 UI 收敛）。

### 1.2 是否涉及数据库变更

**否**。本次为纯前端 UI 标记与样式体系重构，不涉及数据库 schema 变更。

**版本类型判定说明**：按项目版本规则「无 DB 变更 → patch 递增」，严格意义上应为 patch。但本里程碑是横跨全站 29 个文件的设计系统统一（相当于一次完整的视觉架构落地），且项目工作记忆已将其明确记录为 **v0.6.0 里程碑**，故本次按 minor 处理，以与既有项目进度记录保持一致。后续纯修复类变更恢复 patch 递增。

## 三、核心变更

### 3.1 全局主题单点驱动

**问题**：此前颜色散落在各页面 `style` 与 `n-overrides.css` 中，主题切换与品牌色调整需逐页修改。

**修复**：在 `App.vue` 注入 `themeOverrides`（深茶绿主色 `#4A6741`，hover `#5C7A50`，active `#3C5532`；成功 `#67C23A` / 警告 `#E6A23C` / 错误 `#F56C6C` / info `#1677FF`；页面背景 `#F5F7FA`，卡片纯白，圆角 3px，Card 阴影 `0 1px 4px rgba(0,0,0,0.08)`），由 Naive UI 全局生效；`variables.css` 同步 CSS 变量供原生元素与 UnoCSS 复用。

**位置**：`tea-manage/src/App.vue`、`tea-manage/src/styles/variables.css`

### 3.2 图标体系统一为 UnoCSS mdi

**问题**：页面混用 `@vicons/ionicons5`（`i-ic-*`）与部分 mdi，依赖冗余且风格不一。

**修复**：
1. 移除 `@vicons/ionicons5` 依赖（`package.json`）
2. 全部图标改为 UnoCSS `i-mdi-*`（已配置 `@iconify-json/mdi` + presetIcons）
3. 侧边栏 `sidebarMenus.ts` 菜单 icon 字段由 `ic:xxx` 改为 `mdi:xxx` 类名字符串

**位置**：`tea-manage/src/components/layout/Sidebar.vue`、`tea-manage/src/components/layout/MenuConfig.ts`、`tea-manage/package.json`

### 3.3 根节点与布局规范

**问题**：各页面根节点留白、布局写法不一致。

**修复**：
- 所有业务页面根节点统一 `class="tea-page p-md"`（`p-md` = `px-4 py-3`）
- 功能区用 `<n-card>` 包裹
- 间距优先 `<n-space>` / `<n-grid>`，禁止散落 `mt-*`/`mb-*`（仅 1px 边框微调例外）

**位置**：全部 23 个业务视图文件

### 3.4 彩色文字与金额规范

**问题**：彩色文字手写 `style="color:..."` span，深浅主题下易失效；金额字体不统一。

**修复**：
- 彩色文字改 `<n-text :type>` / `:depth>`，自动适配主题
- 金额统一 `font-mono` + 保留两位小数

**位置**：商品/库存/收银/会员等视图

### 3.5 状态可视化与空态规范

**问题**：低库存无颜色预警；空数据无统一文案。

**修复**：
- 低库存变色：称重类 <500g 预警、计件类 <20 个预警、归零 error
- 空态统一：「暂无茶叶数据」「今日尚未开单」

**位置**：商品/库存/仪表盘等视图

## 六、风险评估

### 6.1 高风险项

无。纯 UI 标记/样式重构，业务逻辑未触及。

### 6.2 中风险项

1. **图标类名迁移遗漏**
   - 影响：个别图标不显示
   - 缓解：已全仓检索 `i-ic-*` 确认无残留；构建通过
   - 验证：各页面目测图标

2. **UnoCSS 安全列表**
   - 影响：动态拼接的 mdi 类名若未被扫描可能不生成
   - 缓解：菜单 icon 为静态字符串，`@iconify-json/mdi` 预设可静态解析

### 6.3 低风险项

- `p-md` 由 uno.config 定义，若 uno 配置异常会影响全局留白；已确认配置存在
