## 一、版本概述

v0.5.0 是一次**纯视觉升级**版本，在 v0.4.0 的 UI 框架基础上提升到"质感级"，参照 `D:\AI\AI\JXC` 项目补足视觉差距：

1. **毛玻璃视觉体系** — 标题栏/侧栏/卡片/弹窗/抽屉/下拉全场景应用 backdrop-filter
2. **动效细节** — TabBar 激活指示线动画、Sidebar 激活竖条弹性、按钮 hover 抬升、spring 曲线
3. **工作台欢迎页** — 渐变 Hero + 时段问候 + 6 个快捷操作 + 4 项今日数据
4. **弹窗美化** — Naive UI 弹窗/抽屉/下拉统一覆盖，顶部装饰光带 + 下划线输入框
5. **品牌位置调整** — 标题栏移除品牌，仅侧边栏展示
6. **Naive UI 全套覆盖（n-overrides.css）** — 本轮扩展
7. **侧栏深浅两态** — 茶棕默认 + 米白浅色可切（仿 JXC）
8. **侧栏分组激活增强** — 组内有激活子项时组标题加发光竖条
9. **折叠态侧栏 portal 弹窗菜单** — 仿 JXC 浮窗浏览
10. **登录页（极光背景 + 渐变卡片）** — 多层装饰 + 茶文化文案

### 1.1 设计理念

> **参考项目**：`D:\AI\AI\JXC`（进销存系统）v0.6.0
> **核心原则**：补足 v0.4.0 与 JXC 之间的视觉差距，融入茶易管的中式美学
> **范围限定**：**不改业务逻辑、不改路由、不改 Store、不改后端**

### 1.2 决策记录

| 决策 | 选择 | 理由 |
|------|------|------|
| 毛玻璃范围 | 全局（标题栏/卡片/弹窗/抽屉/下拉/消息） | 提升整体质感 |
| 侧栏背景 | 保持深色实色（不毛玻璃） | 深色背景毛玻璃反而糊 |
| 标题栏高度 | 保持 56px | 已有 48-56 密度档无需变 |
| 品牌位置 | 仅侧边栏 | 用户明确要求；仿 JXC |
| 主色方案 | 3 色全可选 | 用户明确要求 |
| 工作台数据 | Mock 演示 | 当前无后端 API |
| Spring 曲线 | 仅模态/抽屉/弹窗 | 局部使用避免视觉疲劳 |
| Ant 覆盖方式 | 类名 + !important | 抗 Naive UI 版本更新 |
| 侧栏风格 | 深/浅两态可切 | 仿 JXC 主流方案 |
| 折叠态侧栏 | portal 弹窗菜单 | 仿 JXC 提升折叠后体验 |
| 登录页 | 极光 + 渐变卡片 | 仿 JXC 风格 + 茶文化文案 |
| 首页 Tab | 不可关闭 | 仿 JXC 主流方案 |

## 三、变更描述

### 3.1 毛玻璃视觉体系（核心新增）

#### 变量层
```css
/* 半透明背景 + 模糊 */
--tea-titlebar-bg: rgba(250, 246, 241, 0.72);
--tea-card-bg: rgba(255, 255, 255, 0.72);
--tea-modal-bg: rgba(255, 255, 255, 0.88);
--tea-drawer-bg: rgba(255, 255, 255, 0.88);
--tea-overlay-bg: rgba(255, 255, 255, 0.88);

/* 模糊参数 */
--tea-blur-sm: blur(8px);
--tea-blur-md: blur(16px);
--tea-blur-lg: blur(24px);
--tea-card-blur: blur(20px) saturate(180%);
```

#### 应用场景
| 组件 | 效果 |
|------|------|
| 标题栏 | 半透明 + 24px blur，背后内容透出 |
| 卡片（NCard） | 半透明白 + 20px blur + 微边框 |
| 弹窗（NModal） | 半透明白 + 24px blur + 顶部装饰条 |
| 抽屉（NDrawer） | 半透明白 + 24px blur |
| 下拉（NDropdown） | 半透明白 + 20px blur |
| 消息（NMessage） | 半透明白 + 12px blur |
| 自定义卡片 | 同 NCard |

#### 深色主题适配
深色模式下，半透明色对应调整为深棕色（`rgba(31, 24, 18, 0.72)` 等），模糊参数不变。

### 3.2 动效细节

#### TabBar 激活指示线
- **效果**：激活标签底部 2px 主色指示线（左右各缩进 20%）
- **动画**：`scaleX(0) → scaleX(1)` + opacity 淡入，0.3s spring 曲线
- **发光**：`box-shadow: 0 0 8px var(--tea-primary-supply)`

#### Sidebar 激活竖条
- **效果**：激活项左侧 3px 主色竖条（高 70%）
- **动画**：`scaleY(0) → scaleY(1)`，0.3s spring 曲线
- **发光**：`box-shadow: 0 0 8px var(--tea-primary-supply)`

#### 按钮 hover 抬升
- **主按钮**：hover 时 `translateY(-1px)` + 主色阴影 `0 4px 12px`
- **次按钮**：hover 时边框变主色
- **active**：`scale(0.97)`

#### 卡片 hover 抬升
- **效果**：`translateY(-2px)` + 阴影变深 + 边框变主色
- **过渡**：0.25s cubic-bezier(0.4, 0, 0.2, 1)

#### Spring 曲线
```css
--tea-spring: cubic-bezier(0.34, 1.56, 0.64, 1);
```
应用于：指示线、竖条、模态进入、抽屉进入

## 四、关键设计决策

| 决策点 | 选择 | 理由 |
|--------|------|------|
| 毛玻璃实现 | `backdrop-filter` 滤镜 | 现代浏览器原生支持，性能可控 |
| 模糊参数 | 12-24px | 平衡效果与性能 |
| 主色补全方式 | 修改变量值 | 主色切换时所有组件自动跟随 |
| Dashboard 子组件 | 拆 3 个 .vue | 单一职责，便于维护 |
| Mock 数据策略 | 静态 + 随机 | 避免误导用户，标题明确标注"演示数据" |
| 标题栏品牌 | 移除 | 用户明确要求；仿 JXC |
| 侧栏背景 | 不毛玻璃 | 深色背景毛玻璃会糊 |

### 8.2 侧栏深浅两态

- **深色态（默认）**：`rgba(0, 21, 41, 0.92)` 深蓝主色背景，白色文字
- **浅色态**：`rgba(255, 255, 255, 0.78)` 白色半透明 + 模糊，黑色文字
- **切换入口**：主题设置抽屉 → 侧栏风格 segment
- **状态持久化**：localStorage `tea-ui-settings.sidebarStyle`
- **DOM 应用**：`html[data-sidebar-style="dark"|"light"]`

### 8.3 侧栏分组激活增强

- 展开态：组内有激活子项时，组标题左侧 3px 主色发光竖条（带 box-shadow 泛光）
- 折叠态：组内有激活子项时，分组容器左边加 3px 主色发光竖条
- 动画：`scaleY(0) → scaleY(1)`，0.3s spring 曲线

### 8.4 折叠态侧栏 portal 弹窗菜单

- 触发：折叠态下点击分组容器（::after 伪元素显示 24x24 网格图标）
- 位置：分组右侧 + 6px
- 内容：分组标题 + 全部子菜单项
- 交互：
  - 点击子项 → 关闭弹窗 + 跳转路由 + 激活标签
  - 点击遮罩 → 关闭弹窗
  - 弹窗内点击 → 不关闭
  - 展开侧栏 → 自动关闭
  - 路由变化 → 自动关闭
- 动效：scale-in + spring 曲线

### 8.5 登录页（极光背景 + 渐变卡片）

#### 装饰层（4 层）
1. **极光背景**：`radial-gradient` 2 个椭圆 + 30s 漂移动画
2. **网格层**：40px 网格 + 主色 4% 透明度
3. **噪点层**：SVG 噪点（自实现） + 5% 透明度
4. **发光圆点**：3 个固定位置的呼吸光点（v0.5.1 拟扩展为 15 个）
