## 一、版本概述

v0.5.3 是 v0.5.2 之后的**用户反馈专项修复版**，解决用户连续 3 次强调的 5 个核心问题，并扩充演示数据：

1. **深色/浅色模式字体与背景同色** — 加固所有 Naive UI 组件的对比度保护（n-tag/n-alert/n-button/n-data-table/n-tabs/n-menu/n-pagination 等 23+ 个分类）
2. **首页快捷操作与今日概览位置互换** — 用户希望快捷操作作为主区域，今日概览作为侧栏
3. **深色模式下仍有白底残留** — 全局兜底 `bg-white` / `[style*='background: #FFF']` / `dashboard n-card` 三重防御
4. **商品档案列表无法左右滚动** — 新增 8 个字段（分类/类型/基准单位/产地/年份/等级/发酵/焙火/销售单位数/零售价/会员价/总库存/状态/更新时间），编码/名称固定左侧、操作固定右侧，scroll-x 触发横向滚动条
5. **商品档案查看返回列表遮罩残留** — 抽屉/弹窗遮罩关闭后立即隐藏（visibility/display/opacity 三重保险）
6. **演示数据场景不够全面** — 30 个商品 + 12 个供应商 + 20 个会员 + 10 个采购单 + 20 个销售单 + 5 个退货单 + 30 个储值流水 + 5 个库存调整 + 8 个供应商付款，事务保证全部成功插入

### 1.1 设计理念

> **核心原则**：第 3 次强调的"字体背景同色"问题用 28 个分类 CSS 规则终结性兜底，不依赖任何业务组件修改
> **范围限定**：**不改业务逻辑、不改路由、不改 Store、不改后端核心**
> **兼容性**：v0.5.0 / v0.5.1 / v0.5.2 的所有功能 100% 保留
