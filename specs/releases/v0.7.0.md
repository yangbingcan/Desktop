# 茶易管 v0.7.0 版本说明

- **版本**：0.7.0（minor，新增 `return_sale_orders` / `return_sale_items` 两张表，additive 迁移，旧数据无损）
- **日期**：2026-07-15
- **类型**：客户退货闭环 + 数据库备份 + 遗留问题收口

## 新增与调整

### 1. 客户销售退货闭环（CR-02）
- 销售历史新增「退货」操作（仅已完成订单），弹窗加载原单明细，按商品行选择退货数量（上限为原售数量）。
- 后端 `return_sale_order` 命令在单层 `BEGIN EXCLUSIVE` 事务内完成：
  - 按商品类型（称重 `stock_grams` / 计件 `stock_units`）回滚库存；
  - 退货商品作为新批次重新入库（FIFO 后续可正常售出）；
  - 记录 `sale_return` 库存流水；
  - 冲减会员积分与累计消费（不破坏等级判定）；
  - 生成退货单（`return_sale_orders` / `return_sale_items`）。
- 配套：新增 `get_sale_order` 详情命令、前端 `returnSaleOrder` / `getSaleOrder` API 与类型。

### 2. 数据库备份（替换占位）
- 新增 `backup_database` 命令：复制当前 SQLite 为带时间戳副本，存放于应用数据目录 `backups/`。
- 设置页「立即备份」由 `备份功能开发中` 占位改为真实导出，成功后提示备份路径。

### 3. 积分计算修正（IM-03）
- 会员积分由 `actual_amount as i64`（截断）改为四舍五入：`round2(actual_amount).round()`，避免小额订单积分丢失。

### 4. 安全加固（S-6）
- `tauri.conf.json` 由 `csp: null` 改为明确 CSP：`default-src 'self'` + 必要的 `asset:` / `data:` / `ipc:` scheme，关闭空 CSP。
- 注：CSP 已在无 GUI 环境通过编译校验，首次实机运行建议确认 IPC 正常（如异常可临时回退为 `null`）。

### 5. 清理与文档
- 删除未使用的死代码 `stores/sales.ts`（无任何组件 import）。
- 操作手册与实现不符修正：移除不存在的「组合支付」描述、更正备份说明。
