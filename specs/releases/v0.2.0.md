### 退货单创建流程

```
1. validate_return_order(&input)        # 校验输入
2. BEGIN EXCLUSIVE TRANSACTION          # 排他事务
3. SELECT supplier WHERE is_active=1    # 校验供应商
4. FOR each item:
   a. JOIN query batch + product + unit # 查询批次和换算
   b. grams = conversion * quantity     # 计算退货克数
   c. IF remaining < grams => ROLLBACK  # 校验批次库存
   d. UPDATE batches SET remaining      # 扣减批次
   e. UPDATE products SET stock_grams   # 扣减商品总库存
   f. INSERT stock_flow 'return_out'    # 记录流水
   g. INSERT return_items               # 保存明细
5. INSERT return_orders                 # 创建主单
6. COMMIT                              # 提交
```
