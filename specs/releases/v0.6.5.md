# 茶易管 v0.6.5 版本说明

- **版本**：0.6.5（patch，无数据库结构变更）
- **日期**：2026-07-14
- **类型**：功能增强（系统设置关于页改版 + 首页系统操作手册）

## 新增与调整

### 1. 系统设置「关于」页改版
- 新增**演示模式开关**（`n-switch`）：关闭后首页不再显示「演示数据管理」卡片，避免普通用户误操作清空数据。
- 删除原「系统名称 / 技术栈」展示，**仅保留版本号**（通过 `getVersion()` 动态读取 `tauri.conf.json`，始终与安装包一致，杜绝硬编码过期版本）。
- 新增**版本更新内容**：渲染 `changelog.json` 最新一条，以 `n-alert` 列出本次变更点。
- 新增**版本历史**：按时间倒序列出全部版本（版本号标签 + 日期 + 标题），最新版本高亮。

### 2. 首页新增「系统操作手册」卡片
- 新增 `views/dashboard/components/OperationManual.vue`：用 `n-collapse`（手风琴模式）分模块展示操作说明。
- 数据源 `data/operationManual.ts`：覆盖 9 大模块（商品管理 / 库存管理 / 采购入库 / 零售收银 / 会员管理 / 供应商管理 / 退货出库 / 销售报表 / 系统设置），每模块含分步骤 `title` + `desc`，新增模块时只需补充数据，无需改组件。
- 卡片常驻显示，与演示模式开关相互独立。

### 3. 演示模式全局开关
- 新增 `utils/demoMode.ts`：模块级 `ref` + `localStorage` 持久化（key `tea-demo-mode`，存 `0` 关闭 / `1` 开启，默认开启），实现「设置页切换 → 首页即时生效」的跨组件响应式。
