---

## 技术栈详解

### 前端层

| 层次 | 选型 | 说明 |
|------|------|------|
| 前端框架 | Vue 3.4+ (Composition API + `<script setup>`) | 上手快、模板直观、TS 支持够用、生态成熟 |
| 构建工具 | Vite 5+ | 秒级热更新，Rollup 打包，Tree-shaking 极致 |
| UI 组件库 | Naive UI | 全量 Tree-shaking、TS 体验极好、虚拟滚动表格、暗色模式、体积可控 |
| 样式引擎 | UnoCSS（原子化 CSS） | 比 Tailwind 更快更小，按需生成，构建产物极少 |
| 状态管理 | Pinia | Vue 官方推荐，轻量，DevTools 好用 |
| 路由 | Vue Router 4 | 标准答案 |

### 桌面壳层

| 层次 | 选型 | 说明 |
|------|------|------|
| 桌面壳 | Tauri 2.x | 不捆 Chromium，EXE 安装包 6-10MB，内存占用极低 |
| 原生后端逻辑 | Rust (Tauri Commands) | 类型安全、无 GC 停顿、编译后无运行时依赖，库存扣减/事务逻辑写在这里绝对稳 |

### 数据层

| 层次 | 选型 | 说明 |
|------|------|------|
| 数据库 | SQLite (rusqlite/sqlx) | 单文件、零配置、ACID 事务完备，适合单机收银 |
| 数据库加密 | sqlcipher（可选） | 防止店员拷走 db 文件直接看数据 |

### 打印与条码

| 层次 | 选型 | 说明 |
|------|------|------|
| 打印 | Tauri Plugin tauri-plugin-printer / Rust 调用系统打印 API | 小票机、标签机都能打 |
| 条码生成 | 前端 jsbarcode + qrcode | 纯前端足够，不用劳烦 Rust |

### 打包分发

| 层次 | 选型 | 说明 |
|------|------|------|
| 打包工具 | Tauri bundler（NSIS/MSI） | 一键出 Windows 安装包 |

### 未来扩展

| 层次 | 选型 | 说明 |
|------|------|------|
| 局域网同步 | Go/Rust HTTP 服务（可选） | 如果以后开分店，加个后端同步 |

## 项目结构

### 核心模块

1. **商品档案** - 多单位换算、称重类/计件类
2. **出入库管理** - 采购入库、退货出库、报损出库、盘点调整
3. **零售收银** - 收银台、会员识别、支付方式、小票打印
4. **库存管理** - 核心逻辑（FIFO、防超卖）
5. **会员管理** - 基础档案、口味偏好、消费记录
6. **打印模板** - 小票模板、入库/出库单模板、模板编辑器
7. **条码管理** - 条码生成、标签打印、批量打印

### 技术架构

```
┌─────────────────────────────────────────────┐
│                   Vue 3 前端                 │
│  (Naive UI + UnoCSS + Pinia + Vue Router)   │
├─────────────────────────────────────────────┤
│              Tauri 2.x 桌面壳               │
│         (WebView2 / WebKitGTK)              │
├─────────────────────────────────────────────┤
│              Rust 原生后端                   │
│    (Tauri Commands: 库存逻辑/打印/数据库)    │
├─────────────────────────────────────────────┤
│              SQLite 数据库                   │
│           (rusqlite/sqlx + 可选加密)         │
└─────────────────────────────────────────────┘
```
