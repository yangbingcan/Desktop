
## 二、核心理念

### 这个 Skill 做什么？

将你的商业海报需求，通过"诊断→推演→产出"三步，转化为**AI生图模型可直接使用的中文Prompt**，目标是99%还原度、零后处理。

### 三个关键概念

| 概念 | 含义 | 类比 |
|------|------|------|
| **模块（M）** | 海报上的功能区块（如主视觉区、卡片、备注区） | 乐高积木 |
| **配方** | 模块的组合方案（如"配方2"= M1+M2+M3+M4+M5+M6） | 菜谱 |
| **布局（L）** | 模块在画面上的空间排列方式（如左右分栏、全屏沉浸） | 摆盘方式 |

### 容量约束（核心规则）

每种布局有模块容量上限，配方模块数不能超过布局容量：

| 布局 | 容量 | 布局 | 容量 |
|------|------|------|------|
| L1 单栏流式 | 99（万能兜底） | L6 错落阶梯 | 6 |
| L2 左右分栏 | 5 | L7 通栏矩阵 | 8 |
| L3 全屏沉浸 | 4 | L8 破框穿插 | 3 |
| L4 居中对称 | 3 | L9 长图滚动 | 99 |
| L5 极简杂志 | 2 | | |

## 三、完整业务流程

### Step 1：业务与视觉诊断（8个核心变量）

引擎会向你确认8个变量，分两组：

**Part A：业务层（3项）**
1. **行业属性与视觉风格** — 如"医疗专业风""餐饮食欲风""健身高级风"
2. **目标人群核心诉求** — 怕什么/要什么，如"怕衰老、要变美"
3. **核心业务目标** — 拉新/提升客单价/清库存/品牌曝光/私域沉淀

**Part B：视觉与文案层（5项）**
4. **具体文案及重点层级** — 你必须提供真实上版文案，引擎不会编造
5. **色彩偏好与规范** — 品牌色/行业色卡
6. **字体规范** — 标题/正文字体
7. **装饰元素需求** — Logo/徽章/线条/极简无装饰
8. **尺寸与展现形式** — 单屏海报(1080×1920) 或 长图图文(1080×3000~8000)

> **关键**：如果信息不足，引擎会主动提问，不会跳过。你必须提供真实文案，引擎才会进入Step 2。

---

### Step 2：多方案推演（配方 × 布局）

引擎基于Step 1结果，从知识库中匹配2~3套方案供你选择。

**推演逻辑**：
1. 根据业务目标 → 匹配配方（用哪些模块）
2. 根据行业属性 → 匹配布局（怎么摆）
3. 容量校验 → 配方模块数 ≤ 布局容量上限
4. 超容 → 自动排除并推荐精简配方或高容量布局

**输出示例**：
```
方案A：L3 全屏沉浸(4模块) × 配方2s 精简卖货(4模块)
→ 氛围代入感强，适合健身/瑜伽行业
→ 你的重点文案"普拉提小班课"将在毛玻璃浮层中突出

方案B：L6 错落阶梯(6模块) × 配方2 标准卖货(6模块)
→ Z字动线有活力，信息更完整
→ 你的重点文案"普拉提小班课"将在第一个Z字转折处呈现

> 已自动排除：L5 极简杂志(仅容纳2模块，无法承载4模块配方)
```

> **关键**：你必须选择方案后，引擎才进入Step 3。你可以混合调整（如选A的布局+B的配方）。

---

### Step 3：变量填充与Prompt产出

引擎根据你确认的方案，填充所有变量，输出最终Prompt。

**产出包含5部分**：
1. **全局环境设定** — 尺寸、色卡、字体、目标平台
2. **正向Prompt** — 完整的中文视觉描述（从上到下逐层展开）
3. **负向Prompt** — 排除项（基础排除+乱码排除+条件性排除）
4. **推荐生成参数** — 按目标平台提供默认值
5. **自检清单** — 7项指纹核对，全部✅才交付

**7项自检指纹**：
| 核对项 | 核对什么 |
|--------|----------|
| 文案指纹 | 用户原文 vs Prompt中文字，逐字比对 |
| 配色指纹 | 确认的Hex色板 vs Prompt中所有颜色 |
| 布局指纹 | 确认的布局编号 vs Prompt描述的版面骨架 |
| 模块指纹 | 配方模块列表 vs Prompt实际调用的模块 |
| 字体指纹 | 确认的字体族 vs Prompt中字体描述 |
| 装饰指纹 | 确认的装饰清单 vs Prompt中装饰元素 |
| 文字精确度指纹 | 每处文字是否用【】精确包裹+字体+颜色+大小 |

## 五、Prompt撰写9条规则

| 规则 | 核心要求 | 关键点 |
|------|----------|--------|
| 规则1 | 空间顺序+编号分节 | 从上到下描述，每个模块用`1. 2. 3.`编号 |
| 规则2 | 视觉元素具象描述 | 描述"长什么样"而非"参数是什么" |
| 规则3 | 色彩双重标注+色调定性 | `深绿色(#5a7a4e)` + `色彩柔和统一，专业高级感` |
| 规则4 | 文字精确渲染策略 | 三要素(字体+颜色+【原文】)+7项优化技巧+开头声明 |
| 规则5 | 比例与尺寸描述 | 布局用相对比例，视觉细节可用px |
| 规则6 | 模块间衔接描述 | 每个模块开头描述与上一模块的空间关系 |
| 规则7 | 整体风格首尾强化 | 开头描述整体风格，结尾追加风格关键词 |
| 规则8 | 结尾约束声明 | 末尾追加"核心要求"锁死AI自由度 |
| 规则9 | L9分段衔接规则 | 每段独立Prompt，锚点色一致 |

### 示例1：健身普拉提馆（单屏海报）

**你的输入**：
> 我是普拉提馆，想做一张拉新海报，目标人群是女性，关注体态和核心力量训练。主打小班课+私教体验+体态评估。

**引擎流程**：

1. **Step 1 诊断**：行业=健身/瑜伽，目标=拉新引流，主色=#5a7a4e，布局偏好=L3全屏沉浸
2. **Step 2 推演**：
   - 方案A：L3全屏沉浸 × 配方2s精简卖货(4模块)
   - 方案B：L6错落阶梯 × 配方2标准卖货(6模块)
3. **Step 3 产出**：生成完整的中文Prompt，包含正向/负向/参数/自检

**最终Prompt示例**（节选）：
```
生成图片：竖版专业简约高级的女性健身风格商业活动海报，分辨率1080×1920，
所有中文文字必须清晰精确渲染、无乱码无错字无模糊，文字内容严格按描述逐字呈现。
整体色调严格使用莫兰迪深绿色(#5a7a4e)、纯净白色(#ffffff)、浅米白色(#f0f5eb)，
色彩柔和统一，专业感与高级感兼具。

1. 顶部主视觉区（占海报上半部分约1/3高度）
- 背景图：女性做普拉提悬挂训练的特写镜头...
- 叠加半透明深绿色渐变蒙版...
- 左上角：白色手写花体英文【Pilates】
- 右上角：加粗白色大号宋体【塑形卡】

2. 顶部说明区（主视觉区正下方）
...

核心要求：
- 所有文字替换后严格保持原有字体、字号、颜色、对齐方式和位置不变
- 各个模块之间的间距、尺寸比例与描述100%一致
- 视觉层次清晰，整体风格统一，无多余装饰元素
```

## 八、常见问题

**Q：我可以只说"帮我做张海报"吗？**
A：可以，但引擎会主动追问8个核心变量（行业、目标人群、文案等），补齐后才开始生成。

**Q：我可以不用推荐的配方/布局吗？**
A：可以。你可以混合调整（选A布局+B配方），也可以增减模块。但微调后引擎会重新校验容量约束。

**Q：长图和单屏怎么选？**
A：信息量少、一屏能看完→单屏(L1-L8)。信息量大、需要滚动阅读→长图(L9)。如果目标是"活动详情页/课程大纲/深度图文"，引擎会自动倾向长图模式。

**Q：颜色可以自己指定吗？**
A：可以，用户指定色优先于行业色卡推荐。

**Q：为什么有些配方推荐精简版？**
A：因为某些布局（如L3全屏沉浸只能容纳4个模块）容量有限，完整配方(6模块)装不下，所以用精简版保留核心逻辑。

**Q：Prompt为什么是中文？**
A：中文Prompt在GPT-4o/即梦AI等模型上语义更精确，文字渲染更准确。英文仅用于海报上实际出现的英文文字。
