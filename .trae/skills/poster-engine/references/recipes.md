# 预设配方模板 V3.0

> 被 SKILL.md Step 2/3 引用。配方决定"用哪些模块（M）"，与布局正交。
> **容量约束**：每个配方标注 `module_count`，Step 2 推演时对布局的 `max_modules` 做校验。

---

### 配方1：【极简逼格品牌版】
- **适合**：奢侈品、高端沙龙、发布会、品牌曝光
- **模块组合**：M1 + M6
- **模块数**：`module_count` = 2
- **逻辑**：只保留视觉冲击，去掉一切销售感，用留白制造高级感
- **视觉特征**：大量留白、极简文字、高级质感图片

### 配方2：【标准卖货转化版】
- **适合**：大部分体验课、引流款、标准服务
- **模块组合**：M1 + M2 + M3 + M4 + M5 + M6
- **模块数**：`module_count` = 6
- **逻辑**：吸引→痛点→基础方案→进阶方案→裂变→备注，漏斗最完整
- **视觉特征**：信息密度适中，层次分明

### 配方3：【限时逼单秒杀版】
- **适合**：电商大促、节日促销、清库存
- **模块组合**：M1 + M8 + M3 + M5 + M6
- **模块数**：`module_count` = 5
- **逻辑**：跳过痛点教育，直接用倒计时(M8)制造紧迫，抛出单品优惠(M3)，立刻引导下单(M5)
- **视觉特征**：紧迫感强，数字突出，行动按钮醒目

### 配方4：【防反悔信任版】
- **适合**：高客单价如植发、整形、高价训练营
- **模块组合**：M1 + M2 + M3 + M7 + M5 + M6
- **模块数**：`module_count` = 6
- **逻辑**：在用户犹豫时，用专家认证、往期案例、资质保障(M7)推一把
- **视觉特征**：专业权威感，数据/证书突出

### 配方5：【社交裂变传播版】
- **适合**：打卡活动、众筹、社区运营
- **模块组合**：M1 + M11 + M9 + M5 + M6
- **模块数**：`module_count` = 5
- **逻辑**：玩法规则(M11)说明参与方式，社交证明(M9)制造从众，裂变(M5)促传播
- **视觉特征**：互动感强，人群元素多

### 配方6：【多品上新展示版】
- **适合**：零售上新、菜单更新、多SKU展示
- **模块组合**：M1 + M10 + M5 + M6
- **模块数**：`module_count` = 4
- **逻辑**：主视觉定调，多SKU平铺(M10)展示商品，行动号召(M5)引导下单
- **视觉特征**：商品图为主，排列整齐

### 配方7：【新店开业引爆版】
- **适合**：新店开业、品牌首秀、周年庆
- **模块组合**：M1 + M8 + M9 + M5 + M6
- **模块数**：`module_count` = 5
- **逻辑**：主视觉定调(M1)+稀缺感开业限量(M8)+社交证明营造人气(M9)+裂变促到店(M5)
- **视觉特征**：热闹氛围，开业标识醒目，人群/数据元素

### 配方8：【会员专享特权版】
- **适合**：会员日、VIP特权、储值活动
- **模块组合**：M1 + M3 + M4 + M6
- **模块数**：`module_count` = 4
- **逻辑**：主视觉彰显身份(M1)+基础特权(M3)+进阶特权(M4)形成对比锚定，底部标记品牌
- **视觉特征**：尊贵感，金/黑色调，等级差异对比

### 配方9：【节日节气问候版】
- **适合**：节日借势、节气营销、情感连接
- **模块组合**：M1 + M5 + M6
- **模块数**：`module_count` = 3
- **逻辑**：氛围主视觉定调(M1)+轻量行动号召(M5)+品牌落款(M6)，不过度销售
- **视觉特征**：节日氛围浓，文字克制，情感优先于促销

### 精简变体（适配低容量布局）

> 当视觉首选布局容量不足时，使用精简变体保留核心逻辑，去掉非必需模块。
> 命名规则：配方Ns = 配方N的精简版。3模块变体可适配 L4(3)/L8(3)，4模块变体可适配 L2(5)/L3(4)。

### 配方2s：【精简卖货版】
- **适合**：需搭配低容量布局（L2/L3/L4/L8）的标准卖货场景
- **模块组合**：M1 + M3 + M4 + M6
- **模块数**：`module_count` = 4
- **逻辑**：配方2的精简版，去掉痛点说明(M2)和裂变模块(M5)，保留核心卖货漏斗：吸引→基础方案→进阶方案→备注
- **视觉特征**：信息精炼，留白更多，适合氛围感强的布局

### 配方4s：【精简信任版】
- **适合**：需搭配低容量布局的高客单价场景
- **模块组合**：M1 + M3 + M7 + M6
- **模块数**：`module_count` = 4
- **逻辑**：配方4的精简版，去掉痛点说明(M2)和裂变模块(M5)，保留核心信任链：吸引→方案→信任背书→备注
- **视觉特征**：专业权威，留白适中，信任元素突出

### 配方3s：【精简逼单版】
- **适合**：需搭配低容量布局（L4/L8）的限时促销场景
- **模块组合**：M1 + M8 + M3
- **模块数**：`module_count` = 3
- **逻辑**：配方3的精简版，去掉裂变(M5)和备注(M6)，保留核心紧迫链：吸引→倒计时→单品优惠
- **视觉特征**：极简紧迫，倒计时醒目，行动感强

### 配方7s：【精简开业版】
- **适合**：需搭配低容量布局（L4/L8）的新店开业场景
- **模块组合**：M1 + M8 + M5
- **模块数**：`module_count` = 3
- **逻辑**：配方7的精简版，去掉社交证明(M9)和备注(M6)，保留核心开业链：吸引→开业限量→裂变促到店
- **视觉特征**：开业氛围浓，限量标识醒目，行动号召突出

### 配方8s：【精简会员版】
- **适合**：需搭配低容量布局（L4/L8）的会员特权场景
- **模块组合**：M1 + M3 + M4
- **模块数**：`module_count` = 3
- **逻辑**：配方8的精简版，去掉底部备注(M6)，保留核心双卡对比锚定：主视觉+基础特权+进阶特权
- **视觉特征**：双卡对比突出，尊贵感强，无底部备注更紧凑
