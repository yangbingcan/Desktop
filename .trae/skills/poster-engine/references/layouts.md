# 海报布局库 V3.0

> 被 SKILL.md Step 2/3 引用。布局是海报的**版面骨架**，决定各模块在画面上的空间关系。
> **容量约束**：每种布局有 `max_modules` 上限，Step 2 推演时配方模块数不得超出此值，超出则自动排除。
> **拼接模式**：L9 支持将多个 L1-L8 子布局纵向拼接成一幅长图，段间使用过渡样式连接。

---

## 布局容量速查

| 布局 | max_modules | 尺寸范式 | 理由 |
|------|-------------|----------|------|
| L1 单栏流式 | 99 | 单屏(1080×1920) | 自上而下堆叠，无上限，兜底方案 |
| L2 左右分栏 | 5 | 单屏(1080×1920) | 文侧空间有限，超过5个模块会拥挤失衡 |
| L3 全屏沉浸 | 4 | 单屏(1080×1920) | 浮层卡片不宜过多，破坏沉浸感 |
| L4 居中对称 | 3 | 单屏(1080×1920) | 双卡结构简单，多模块则对比焦点被稀释 |
| L5 极简杂志 | 2 | 单屏(1080×1920) | >40%留白，文字极度克制 |
| L6 错落阶梯 | 6 | 单屏(1080×1920) | Z字动线每级1模块，6级仍可读 |
| L7 通栏矩阵 | 8 | 单屏(1080×1920) | 网格排列，双列/三列可容纳较多信息 |
| L8 破框穿插 | 3 | 单屏(1080×1920) | 视觉焦点优先，模块多则冲击力被稀释 |
| L9 长图滚动式 | 99 | 长图(1080×3000~12000) | 纵向拉伸近乎无限，支持多布局拼接 |

### L1 — 单栏流式（万能百搭）
- **核心特征**：自上而下线性排列，模块依次堆叠，阅读逻辑最顺畅
- **适合场景**：万能百搭，任何行业/目标的兜底方案；容量不足时自动降级选此
- **视觉关键词**：简洁线性流式，自上而下堆叠
- **容量**：`max_modules` = 99（无限制）
- **布局参数**：
  - `flow_direction`：vertical（固定）
  - `column_count`：1（固定）
  - `section_gap`：模块间距（默认 24px）
  - `edge_padding`：左右边距（默认 28px）
- **重点文案呈现**：通常在 M1 底部或独立段落以大标题呈现

### L2 — 左右分栏（显质感）
- **核心特征**：左图右文（或左文右图），图文分庭抗礼，高级质感
- **适合场景**：高客单价、品牌调性优先、奢侈品/医美/珠宝/金融
- **视觉关键词**：左右分栏，左图右文，编辑质感
- **容量**：`max_modules` = 5
- **布局参数**：
  - `split_ratio`：左右比例（默认 4:6 或 5:5）
  - `split_direction`：left-image / right-image
  - `vertical_alignment`：center / top
  - `gap`：图文间距（默认 32px）
- **重点文案呈现**：常在文侧独立呈现，利用留白制造呼吸感

### L3 — 全屏沉浸（代入感）
- **核心特征**：大图满铺全屏作为背景，文字与卡片以毛玻璃/半透明浮层叠加其上
- **适合场景**：氛围代入、情感营销、餐饮/旅行/美妆/宠物
- **视觉关键词**：全出血大图，毛玻璃浮层，沉浸氛围
- **容量**：`max_modules` = 4
- **布局参数**：
  - `bg_image_coverage`：100%（固定，满铺）
  - `overlay_style`：frosted-glass / gradient-mask / dark-matte
  - `card_opacity`：0.7-0.9（毛玻璃透明度）
  - `text_position`：bottom-center / center / top-center
- **重点文案呈现**：浮层卡片中的核心文字，与背景产生纵深层次

### L4 — 居中对称（对比促单）
- **核心特征**：双卡/双元素以中轴线镜像对称，对比强烈
- **适合场景**：对比促单选（基础版 vs 升级版）、裂变活动
- **视觉关键词**：居中对称，双卡对比，镜像布局
- **容量**：`max_modules` = 3
- **布局参数**：
  - `symmetry_axis`：vertical（中轴线方向）
  - `card_count`：2（默认双卡）
  - `card_width_ratio`：每卡占比（默认各 45%）
  - `center_accent`：中轴装饰元素（可选：VS / 箭头 / 分割线）
- **重点文案呈现**：双卡之间焦点位，或中轴线上方标题位

### L5 — 极简杂志（高冷感）
- **核心特征**：大量留白（通常 >40%），抠图主体悬浮，文字极度克制
- **适合场景**：奢侈品、高端沙龙、发布会、品牌曝光、汽车
- **视觉关键词**：杂志编辑风，大量留白，抠图主体，极简
- **容量**：`max_modules` = 2
- **布局参数**：
  - `negative_space_ratio`：留白占比（默认 45%）
  - `subject_style`：cutout / silhouette / centered-product
  - `text_density`：minimal（通常 ≤3 行文字）
  - `text_position`：bottom-right / centered / top-left
- **重点文案呈现**：极简文字在大量留白中天然成为唯一焦点

### L6 — 错落阶梯（读得下去）
- **核心特征**：Z 字视觉动线，模块左右交错排列，节奏生动
- **适合场景**：内容多但不想显拥挤、教育/培训/活动规则说明/家居
- **视觉关键词**：Z字动线，左右交错，动态阅读节奏
- **容量**：`max_modules` = 6
- **布局参数**：
  - `flow_pattern`：zigzag（固定）
  - `alternate_start`：left / right（首模块起始侧）
  - `step_offset`：每级偏移量（默认 40px）
  - `connector_style`：arrow / line / none
- **重点文案呈现**：通常在第一个 Z 字转折处（视觉落点第一站）

### L7 — 通栏矩阵（信息铺满）
- **核心特征**：横向铺满，双列/三列网格排列，信息密度高但不乱
- **适合场景**：大促多品展示、多 SKU、菜单/活动规则、电商
- **视觉关键词**：网格矩阵，多列布局，密集有序
- **容量**：`max_modules` = 8
- **布局参数**：
  - `column_count`：2 / 3
  - `row_count`：动态（由内容决定）
  - `cell_aspect`：1:1 / 4:3 / 3:2
  - `grid_gap`：单元格间距（默认 16px）
- **重点文案呈现**：首格或末格放大为焦点位，其他为等大排列

### L8 — 破框穿插（抓眼球）
- **核心特征**：主体元素突破模块边界，形成 3D 纵深感与视觉张力
- **适合场景**：年轻潮流、运动品牌、新品引爆、茶饮、新店开业
- **视觉关键词**：破框而出，3D纵深，元素穿插，动态张力
- **容量**：`max_modules` = 3
- **布局参数**：
  - `break_element`：突破边界的元素（人物/产品/文字）
  - `break_direction`：top / left / right / center-burst
  - `depth_layers`：纵深层次数（默认 3 层）
  - `shadow_intensity`：投影强度（强/中/弱，增强 3D 感）
- **重点文案呈现**：突破边框的超大文字，成为视觉锤

### L9 — 长图滚动式（信息叙事 + 多布局拼接）

- **核心特征**：纵向分段展开，支持将多个 L1-L8 子布局拼接成一幅长图。每段独立拥有视觉焦点，段间用过渡样式连接，形成连贯的滚动阅读体验。
- **适合场景**：活动详情页、课程大纲、产品说明书、小红书深度图文、年度报告、会议纪要
- **视觉关键词**：长卷信息图，纵向叙事，分段连贯
- **容量**：`max_modules` = 99（纵向拉伸近乎无限，但建议每段 ≤3 个模块）
- **尺寸范式**：1080×(3000~12000)px，建议 ≤8000px 以保证 AI 生成质量；超长图建议分段生成后拼接

#### 拼接模式（核心能力）

L9 不是单一的"版面骨架"，而是一个**纵向拼接容器**。使用时需定义一个 `sections` 数组：

```yaml
sections:
  - id: 1
    sub_layout: L3         # 此段使用哪种布局
    height_ratio: 0.35     # 占总高度比例
    recipe: 配方1          # 此段用哪个配方的模块
    role: "开场"           # 此段的叙事角色（开场/主体/高潮/收尾）
  - id: 2
    sub_layout: L7
    height_ratio: 0.40
    recipe: 配方6
    role: "主体"
  - id: 3
    sub_layout: L1
    height_ratio: 0.25
    recipe: 配方1
    role: "收尾"
```

**布局参数：**
- `sections`：段定义数组（最少 2 段，建议 3~5 段）
  - `sub_layout`：此段采用哪个 L1-L8 子布局
  - `height_ratio`：此段占比（所有段之和=1.0）
  - `recipe`：此段填充哪个配方的模块
  - `role`：叙事角色（开场 / 主体 / 高潮 / 收尾）
- `total_height`：总高度（默认 3000~6000px）
- `transition`：段间过渡样式（整图统一，或每段单独指定）

#### 过渡样式库（解决段间生硬拼接）

| 过渡类型 | 视觉效果 | 最适合 | 参数 |
|----------|----------|--------|------|
| **color-block** | 纯色条带分隔（高度 40~80px） | 段落间需要明确分界 | `block_color`, `block_height` |
| **gradient-fade** | 上下两段背景色渐变过渡 | 同色系段落，柔和衔接 | `fade_height`, `direction` |
| **whitespace-breath** | 大段留白呼吸区（高度 60~120px） | 信息密度高时制造喘息 | `breath_height` |
| **decorative-divider** | 装饰分割线/波形/虚线/图标 | 品牌感强的内容 | `divider_style`, `divider_thickness` |
| **color-shift** | 上下段背景色交替（如浅灰→白→浅灰） | 多段长图，节奏清晰 | `color_sequence[]` |
| **seamless-continue** | 无缝衔接，无任何过渡 | 相邻段布局相同或信息需连续 | （无参数） |

#### 段内容量约束（关键规则）

虽然 L9 总容量 99，但**每个段受其子布局的 `max_modules` 限制**（以下为逻辑说明，非可执行代码）：

```
对 L9 的每个段:
  如果 该段配方.module_count ≤ 该段子布局.max_modules:
    → 通过
  否则:
    → 不允许，提示用户："第X段使用[L布局]无法容纳配方[X]的Y个模块，建议替换子布局或配方"
```

#### 重点文案呈现

- 长图中"唯一重点文案"通常放在 `role: 开场` 段（首段，占比最大）
- 如需多个核心文案分段呈现，每段 `role` 可标注 `高潮`，使该段文字成为本段焦点

## 布局 × 行业速配表

> **容量提示**：首选布局为视觉最优解，需搭配精简配方（4模块如配方2s/4s适配L2/L3，3模块如配方3s/7s/8s适配L4/L8）；若需完整配方（5~6模块），请选用次选布局或高容量布局（L1/L6/L7）。

| 行业/场景 | 首选布局 | 次选布局 | 理由 |
|-----------|----------|----------|------|
| 奢侈品/珠宝 | L5 极简杂志 | L2 左右分栏 | 留白显高级，左右分栏显质感 |
| 医美/整形 | L2 左右分栏 | L6 错落阶梯 | 左图右文专业感（需配方4s），阶梯对比方案（可容纳完整配方4） |
| 健身/瑜伽 | L3 全屏沉浸 | L6 错落阶梯 | 氛围代入首选（需配方2s），Z字动线有活力（可容纳完整配方2） |
| 餐饮/烘焙 | L3 全屏沉浸 | L7 通栏矩阵 | 食欲氛围满铺（需配方2s/6），矩阵展示多品 |
| 科技/SaaS | L1 单栏流式 | L5 极简杂志 | 逻辑清晰稳妥，极简科技感 |
| 教育/培训 | L6 错落阶梯 | L1 单栏流式 | Z字动线易读，线性逻辑清晰 |
| 美妆/护肤 | L3 全屏沉浸 | L6 错落阶梯 | 氛围感强（需配方2s/4s），左右分栏高级（可容纳完整配方） |
| 电商大促 | L7 通栏矩阵 | L8 破框穿插 | 信息铺满（可容纳配方3），破框引爆眼球（需配方3s） |
| 金融/保险 | L2 左右分栏 | L6 错落阶梯 | 专业信任感（需配方4s），简洁稳重（可容纳完整配方4） |
| 品牌曝光 | L5 极简杂志 | L3 全屏沉浸 | 高级冷艳，纯粹视觉冲击 |
| 社交裂变 | L6 错落阶梯 | L7 通栏矩阵 | Z字动线引导参与（可容纳配方5），矩阵铺满玩法信息 |
| 新店开业 | L7 通栏矩阵 | L8 破框穿插 | 矩阵铺满开业信息（可容纳配方7），破框吸睛（需配方7s） |
| 母婴/亲子 | L3 全屏沉浸 | L6 错落阶梯 | 温馨氛围（需配方2s/4s），Z字展示服务项（可容纳完整配方） |
| 宠物 | L3 全屏沉浸 | L6 错落阶梯 | 萌宠满铺代入感（需配方2s/6），Z字展示服务项 |
| 茶饮/咖啡 | L7 通栏矩阵 | L8 破框穿插 | 矩阵展示多款（可容纳配方3/6），破框潮流吸睛（需配方3s） |
