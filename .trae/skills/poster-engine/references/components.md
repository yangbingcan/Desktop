# 组件库 V3.0

> 被 SKILL.md Step 2/3 引用。模块描述海报中的功能区块，配方从中选取组合。
> **V3.0 更新**：每个模块新增「视觉描述模板」，指导如何将参数转化为生图模型可理解的视觉化自然语言。

---

### M1 — 主视觉头图区
- **功能定位**：3秒抓眼，传递行业与场景
- **适用场景**：所有海报必选
- **参数变量**：
  - `hero_image`：主视觉画面描述（人物/场景/产品特写）
  - `hero_overlay`：叠加蒙版样式（渐变色/纯色/无）
  - `hero_text_top_left`：左上角文字（主标题+副标题）
  - `hero_text_top_right`：右上角文字（标签/徽章）
  - `hero_height_ratio`：占海报高度比例（默认1/3）
- **视觉描述模板**：
  ```
  顶部主视觉区（占海报上半部分约{hero_height_ratio}高度）
  - 背景图：{hero_image的详细视觉描述}
  - 叠加{hero_overlay的视觉描述，如：半透明深绿色渐变蒙版，从下往上由深变浅}
  - 左上角：{hero_text_top_left的字体样式+颜色+内容}
  - 右上角：{hero_text_top_right的字体样式+颜色+内容}
  ```

- **hero_image描述维度清单（强制逐项覆盖）**：
  ```
  hero_image必须包含以下6个维度的描述，缺一不可：
  1. 主体内容：人物/产品/场景的具体内容（如"女性做普拉提悬挂训练的特写镜头"）
  2. 构图方式：特写/中景/全景/俯拍/仰拍（如"特写镜头，仅露出手臂、腰腹和腿部"）
  3. 穿着/外观：人物穿着或产品外观细节（如"穿着浅灰色长袖运动上衣和黑色紧身瑜伽裤"）
  4. 动作/姿态：人物动作或产品摆放（如"双手握住木质横杆，横杆连接黑色金属弹簧和吊绳"）
  5. 环境背景：场景环境描述（如"背景是模糊的白色室内瑜伽馆环境"）
  6. 光线质感：光照和画面质感（如"有柔和的自然光照射，画面质感细腻高级"）
  ```

### M2 — 痛点/卖点说明区
- **功能定位**：承接兴趣，解释主旨
- **适用场景**：需要教育用户的非标服务（如健身、医美、教育）
- **参数变量**：
  - `desc_lines`：说明文字行数组（每行内容）
  - `desc_alignment`：对齐方式（左对齐/居中）
  - `desc_line_spacing`：行间距倍数（默认1.2）
- **视觉描述模板**：
  ```
  顶部说明区（主视觉区正下方）
  - {desc_alignment}排列，{文字颜色}常规{字体族}，行间距{desc_line_spacing}倍
  - 逐行列出：{每行内容用【】包裹}
  ```

### M3 — 核心权益卡片A
- **功能定位**：主推商品/服务展示
- **适用场景**：单品推销、基础套餐
- **参数变量**：
  - `card_title`：卡片标题（如"单人购买"）
  - `card_subtitle`：卡片右侧英文标识
  - `card_items`：权益列表数组（每项内容）
  - `card_header_color`：标题栏背景色
  - `card_body_color`：卡片主体背景色
- **视觉描述模板**：
  ```
  {card_title}卡片模块（上一模块正下方）
  - 圆角矩形卡片，浅灰色细边框，圆角半径{全局圆角}，内边距均匀
  - 顶部{card_header_color的中文名+Hex}标题栏，高度占卡片1/6，左右圆角与卡片一致
  - 标题栏左侧：白色加粗{字体族}【{card_title}】
  - 标题栏右侧：白色大写粗体英文【{card_subtitle}】
  - 卡片主体{card_body_color的中文名+Hex}背景
  - 主体内容：{文字颜色}常规{字体族}项目符号列表，每个项目前加黑色实心圆点，行间距{全局行间距}倍，左对齐
    {逐项列出，每项用【】包裹}
  ```

### M4 — 进阶权益卡片B
- **功能定位**：升级版/组合版展示
- **适用场景**：对比锚定、提升客单价
- **参数变量**：同M3（样式与M3完全一致，内容不同）
- **视觉描述模板**：同M3，开头改为 `{card_title}卡片模块（上一卡片正下方，尺寸样式完全一致）`

### M5 — 裂变/行动号召模块
- **功能定位**：促分享、促留资
- **适用场景**：拉新活动、私域沉淀
- **参数变量**：
  - `share_image`：缩略图画面描述
  - `share_image_label`：缩略图上的叠加文字
  - `share_icon`：缩略图上的叠加图标（可选，如箭头/手指/分享图标，默认无图标）
  - `share_lines`：右侧文字行数组（3行：常规+加粗加大+小字）
  - `share_bg_color`：模块背景色
- **视觉描述模板**：
  ```
  转发活动模块（上一模块正下方）
  - {share_bg_color的中文名+Hex}背景圆角矩形模块，浅灰色细边框，圆角半径{全局圆角}，内边距均匀
  - 左侧：正方形图片占位框，浅灰色细边框，内部显示{share_image的视觉描述}，缩略图叠加白色半透明蒙版{share_icon条件描述：若有图标则写"和白色箭头图标"等，若无图标则省略此部分}和白色文字【{share_image_label}】
  - 右侧：三行{desc_alignment}排列{文字颜色}{字体族}文字
    - 第一行：常规字号【{share_lines[0]}】
    - 第二行：加粗加大字号【{share_lines[1]}】
    - 第三行：小字号【{share_lines[2]}】
  ```

### M7 — 信任背书区
- **功能定位**：打消顾虑，建立权威
- **适用场景**：高客单价、试错成本高的行业（医美、金融、教育）
- **参数变量**：
  - `trust_type`：背书类型（专家认证/往期案例/资质保障/数据成果）
  - `trust_items`：背书内容数组
  - `trust_style`：展示样式（图标列表/数据卡片/证书墙）
- **视觉描述模板**：
  ```
  信任背书区（上一模块正下方）
  - {trust_style的视觉描述}：
    - 图标列表：横向排列的圆形图标+下方文字标签，{文字颜色}{字体族}
    - 数据卡片：小圆角矩形卡片组，每个卡片内大号数字+下方小字说明
    - 证书墙：网格排列的证书/资质图片缩略图，浅灰色细边框
  - 背书内容：{逐项列出，每项用【】包裹}
  ```

### M8 — 稀缺/倒计时模块
- **功能定位**：制造紧迫感，逼单
- **适用场景**：限时抢购、早鸟价、限量发售
- **参数变量**：
  - `scarcity_type`：稀缺类型（限时倒计时/限量名额/早鸟截止）
  - `scarcity_text`：紧迫感文案
  - `scarcity_number`：数字展示（如"仅剩XX位"/"倒计时XX天"）
  - `scarcity_urgency_level`：紧迫等级（高/中/低，影响视觉冲击力）
- **视觉描述模板**：
  ```
  稀缺提醒模块（上一模块正下方）
  - {scarcity_urgency_level视觉映射：高=红色醒目背景+大号数字 / 中=强调色背景+中号数字 / 低=浅色背景+常规数字}
  - 核心数字：超大号加粗{字体族}，{强调色}，{scarcity_number}
  - 辅助文案：{文字颜色}常规{字体族}【{scarcity_text}】
  ```

### M9 — 排行榜/社交证明
- **功能定位**：从众心理，引发FOMO
- **适用场景**：竞技类（步数榜）、众筹类、打卡类活动
- **参数变量**：
  - `social_proof_type`：证明类型（排行榜/参与人数/好评率/打卡记录）
  - `social_proof_data`：展示数据（如"已有328人参与"/"好评率98%"）
  - `social_proof_style`：展示样式（数字大字/头像列表/进度条）
- **视觉描述模板**：
  ```
  社交证明模块（上一模块正下方）
  - {social_proof_style的视觉描述}：
    - 数字大字：居中超大号加粗数字，下方小字说明
    - 头像列表：横向排列的圆形头像图标（5-8个），右侧数字+文字
    - 进度条：横向填充条+百分比数字
  - 数据内容：【{social_proof_data}】
  ```

### M10 — 多SKU轮播/平铺区
- **功能定位**：多款商品同台展示
- **适用场景**：零售、电商、菜单（如：春季上新3款平铺）
- **参数变量**：
  - `sku_count`：商品数量
  - `sku_items`：商品数组（每个含：名称、价格、图片描述）
  - `sku_layout`：布局方式（横向平铺/纵向列表/网格）
  - `sku_show_price`：是否展示价格
- **视觉描述模板**：
  ```
  多商品展示区（上一模块正下方）
  - {sku_layout的视觉描述}排列{sku_count}个商品卡片
    - 横向平铺：等宽圆角矩形卡片横向排列，每个卡片上方商品图+下方名称{+价格}
    - 纵向列表：全宽列表行，左侧商品图+中间名称+右侧价格
    - 网格：2×N网格，每个格子商品图+名称{+价格}
  - 每个商品：{逐个描述图片内容+名称+价格，用【】包裹文字}
  ```

### M11 — 互动/玩法规则区
- **功能定位**：解释复杂参与机制
- **适用场景**：投票、签到集章、抽奖转盘等活动
- **参数变量**：
  - `rules_steps`：规则步骤数组（按序排列）
  - `rules_style`：展示样式（步骤条/编号列表/流程图）
  - `rules_highlight`：需高亮的关键步骤
- **视觉描述模板**：
  ```
  玩法规则区（上一模块正下方）
  - {rules_style的视觉描述}：
    - 步骤条：横向编号圆圈+箭头连接+下方文字说明
    - 编号列表：纵向排列的编号+文字，行间距均匀
    - 流程图：带箭头的流程框图，每框内文字说明
  - 规则步骤：{逐行列出，关键步骤标注"加粗高亮"，用【】包裹文字}
  ```
