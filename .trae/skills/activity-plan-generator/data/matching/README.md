# 22行业×11目标 活动匹配关系

## 11个活动目标体系

### 目标分类

| 维度 | 目标 | 定义 | 衡量指标 | 与其他目标的区别 |
|------|------|------|---------|---------------|
| 获客 | **拉新客** | 让从未到店的人首次到店 | 新客到店数/新客转化率 | — |
| 获客 | **品牌曝光** | 让更多人知道你的存在 | 曝光量/到店咨询量 | 拉新客=到店，品牌曝光=知道你 |
| 留存 | **老客复购** | 让老客户继续消费 | 续卡率/复购率 | — |
| 留存 | **唤醒沉睡客户** | 让3个月+未到店的客户重新到店 | 唤醒率/回归率 | 与老客复购的区别：沉睡客户需要"重新激活"而非"续购" |
| 留存 | **提升到店频次** | 让客户来得更频繁 | 月均到店次数/缺课率 | 到店频次低→续卡率低→储值消耗慢，是独立问题 |
| 留存 | **提升转介绍率** | 让更多老客户主动推荐 | 转介绍率/推荐人数 | 老带新是活动，提升转介绍率是目标 |
| 交易 | **提客单价** | 让客户每次花更多钱 | 客单价/单次消费额 | — |
| 交易 | **提升连带率** | 让客户一次买更多件 | 连带率/件单价 | 连带率≠客单价：买1件1000元=客单价高但连带率低 |
| 商品 | **清库存** | 清理滞销品/换季品 | 库存周转天数/清仓率 | — |
| 商品 | **推新品** | 推广新产品/新课程 | 新品销量/新品体验人数 | — |
| 锁客 | **储值锁客** | 通过预付储值锁定客户长期消费 | 储值金额/储值客户数/储值消耗率 | 与老客复购的区别：复购是"继续买"，储值是"先付钱锁定未来消费"。**注：储值锁客具有双重属性——既是经营目标，也是实现复购/到店频次提升的手段** |

### 目标之间的逻辑关系

```
品牌曝光 → 拉新客 → 首次到店 → 体验转化 → 老客复购 → 提升到店频次 → 储值锁客
                                    ↓              ↓
                               提升转介绍率     提客单价/提升连带率
                                    ↓
                                 拉新客（循环）

清库存/推新品 = 独立目标，但可以和上述循环结合
```

## 核心匹配逻辑

### 匹配三原则

**原则1：边际成本决定"能不能送"**
- 边际成本低 → 可以"送体验课/送课" → 老带新/体验卡/预存礼包/打卡签到是标配
- 边际成本高 → 不能"送"，只能"减"或"赠" → 满减/满额赠/预存礼包/福袋盲盒是标配

**原则2：决策周期决定"转化路径"**
- 决策周期长 → 必须有"体验/试用"环节 → 沙龙/品鉴会/公开课是转化前提 → 老带新是最高效获客
- 决策周期短 → 即时决策，冲动消费 → 团购/秒杀/闪购/储值/拼团是标配

**原则3：复购模式决定"锁客方式"**
- 复购模式=持续消费 → 储值锁客/订阅制是核心 → 续卡/续费优惠/集点/会员日是标配
- 复购模式=低频高客单 → 每一单做到极致 → VIP沙龙/深度体验是转化前提

### 匹配验证规则（防止瞎推荐）

每个推荐必须通过以下4项验证，否则不能推荐：

| 验证项 | 检查内容 | 不通过的后果 |
|--------|---------|------------|
| **1.边际成本验证** | 推荐的活动是否与行业边际成本匹配？ | 边际成本高的行业推荐"送体验课"=亏钱 |
| **2.决策周期验证** | 推荐的活动是否与客户决策周期匹配？ | 决策周期长的行业推荐"秒杀"=没人秒 |
| **3.团队规模验证** | 推荐的活动是否与团队规模匹配？ | 1人工作室推荐"沙龙"=做不了 |
| **4.预算验证** | 推荐的活动是否在预算范围内？ | 预算500元推荐"沙龙"=超预算 |

## 匹配质量自检清单

每次推荐活动时，必须通过以下自检：

| # | 自检项 | 通过标准 | 不通过的处理 |
|---|--------|---------|------------|
| 1 | 边际成本匹配？ | 低边际成本行业推荐"送"类活动，高边际成本推荐"减/赠"类 | 调整推荐 |
| 2 | 决策周期匹配？ | 长决策周期行业必须有体验环节 | 增加体验环节 |
| 3 | 团队规模匹配？ | 1人工作室不推荐需要3-5人的活动 | 降级为1人可做的替代方案 |
| 4 | 预算匹配？ | 活动成本在用户预算范围内 | 调整为低预算方案 |
| 5 | 时节匹配？ | 活动主题与当前节气/节日/天气匹配 | 调整主题或时间 |
| 6 | 有推荐理由？ | 每个推荐都有"为什么选这个" | 必须补充 |
| 7 | 有成功必然因素？ | 每个推荐都有"必须满足什么才能成功" | 必须补充 |
| 8 | 有成功注意因素？ | 每个推荐都有"执行中必须注意的环节细节" | 必须补充 |
