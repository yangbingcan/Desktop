# 眼镜店/视力矫正

每个推荐包含：**推荐理由** + **成功必然因素** + **成功注意因素**

### 成功必然因素 vs 成功注意因素

- **成功必然因素** = 不满足就做不成的硬性前提。每条2-3个，用"必须"开头。缺少任何一个，活动大概率做不成。
- **成功注意因素** = 执行中容易踩的坑和容易忽略的细节。与必然因素不重复。每条2-3个，用具体场景描述。注意到位了成功率翻倍。
