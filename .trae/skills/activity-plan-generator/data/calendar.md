# 日历·节气·天气·活动时机参考

> 版本：同 SKILL.md | 更新日期：同 SKILL.md
>
> **天气影响数据说明**：本文中"到店率下降X%"等数据为行业经验估算值，综合参考了零售/餐饮/服务业多年运营经验。实际影响因城市、行业、商圈而异，仅供参考。建议结合当地实际天气和到店数据校准。
>
> **重要说明**：以下节气日期为大致日期，每年可能相差1-2天。具体日期请以当年万年历为准。如用户提到具体年份，务必通过WebSearch查询该年准确节气日期。

> **农历节日公历日期**：春节、端午、中秋、七夕等农历节日的公历日期每年不同。当用户提到活动时间涉及农历节日时，务必通过WebSearch查询该年农历节日对应的公历日期（如"2026年春节是几月几号"），不可仅凭农历日期估算。
>
> **实时天气查询**：本文件提供季节性参考数据。在Phase 2中，必须使用 Open-Meteo API（免费、无需API Key）查询用户城市的实时天气预报，获取活动期间的精准气温、降水概率、风速等数据。API调用方式详见 SKILL.md。仅当API不可用时，才回退到本文件的静态数据。
>
> **天气+节气联合展示**：在向用户展示时机分析时，必须将节气信息和天气信息**同时呈现**，不可分开。展示模板详见 SKILL.md Phase 2 "天气+节气联合展示模板"。
>
> **天气预报范围限制**：Open-Meteo 免费版仅支持未来16天预报。活动日期超出16天时，使用本文件的季节性天气数据作为参考，并标注"（基于季节性参考，非实时预报）"。

## 天气与活动影响

### 天气对线下活动的影响

| 天气条件 | 对线下活动的影响 | 应对策略 |
|---------|---------------|---------|
| 暴雨/台风 | 到店率下降50-80% | 转线上直播/私信秒杀/延期通知提前24h |
| 高温(>35°C) | 到店率下降20-30% | 强调"清凉""避暑"/增加空调体验 |
| 严寒(<0°C) | 到店率下降30-40% | 强调"温暖""暖冬"/提供热饮 |
| 梅雨季 | 到店率下降15-25% | 祛湿主题/室内活动为主 |
| 秋高气爽 | 到店率最高 | 户外活动/体验课高峰期 |
| 雾霾天 | 到店率下降10-20% | 强调室内运动/空气净化 |

> **数据来源说明**：以上天气影响数据为行业经验估算值，综合参考了中国连锁经营协会、美团研究院等公开报告中的零售/餐饮客流数据，以及一线运营人员经验反馈。实际影响因城市、行业、商圈而异，仅供参考。

### 活动排期天气检查清单

在确定活动日期时，必须检查：
1. 是否在梅雨季/台风季？→ 准备线上备选方案
2. 是否在极端高温/严寒期？→ 调整活动时间（避开正午/晚间）
3. 是否有重大天气预报？→ 提前24h通知延期/转线上
4. 活动是否适合户外？→ 准备室内备选场地
5. 节气是否与活动主题契合？→ 借节气做主题营销
