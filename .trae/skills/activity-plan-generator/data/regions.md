## 1. 闽南地区（泉州/厦门/漳州/晋江/石狮）

| 维度 | 特征 |
|------|------|
| 核心城市 | 泉州、厦门、漳州、晋江、石狮、南安 |
| 文化标签 | 爱拼才会赢、宗族观念强、重面子、茶文化、宗教信仰浓厚 |
| 消费心理 | ① 面子消费重：品牌意识强，"穿出去要有面子" ② 价格敏感但不抠门：愿意为品质和面子花钱，但不喜欢被当冤大头 ③ 口碑极度依赖：亲戚朋友说好>广告说好 ④ 宗族/同乡推荐效力极强 |
| 商业习俗 | ① 做生意讲究"交情"：先交朋友再做生意 ② 茶桌文化：很多生意在茶桌上谈成 ③ 红包文化：开业/活动送红包是惯例 ④ 佛诞/庙会：重要商业节点，比法定节日更受重视 |
| 消费高峰 | ① 佛诞日（各村镇不同，全年分布） ② 普渡（农历七月） ③ 元宵节（泉州灯会极盛） ④ 中秋博饼（闽南独有，9月） ⑤ 宗族祭祖（清明/冬至） |
| 沟通偏好 | ① 闽南语为日常语言，但商业场合普通话为主 ② 喜欢拉家常、攀关系，不喜欢直奔主题 ③ "阿姐""阿哥"称呼拉近距离 |
| 活动注意事项 | ① **佛诞日不可忽视**：各村镇佛诞日是消费高峰，要提前了解当地佛诞日排期 ② **普渡月（农历七月）禁忌**：闽南普渡月有些客户忌讳"促销""打折"字眼，活动主题宜用"回馈""感恩" ③ **中秋博饼是黄金节点**：9月活动必须融入博饼元素 ④ **宗族口碑是第一渠道**：老带新/闺蜜同行在闽南效力×3 ⑤ **茶文化融入**：到店礼可送茶叶/茶具，活动可设"品茶+试衣" ⑥ **面子消费**：满额赠礼比折扣更受欢迎（折扣=降价=没面子） |
| 活动话术风格 | ① 热情直接，多用"姐""哥"称呼 ② 强调"品质""面子""别人都买了" ③ "这款卖得最好"比"这款最便宜"更有效 ④ 宗族推荐："您表姐也买了这件" |
| 禁忌 | ① 农历七月避免"清仓""甩卖"等字眼 ② 不要忽视当地庙会/佛诞日 ③ 不要在客户面前说竞品坏话（闽南商人圈子互通信息） |

## 2. 潮汕地区（汕头/潮州/揭阳）

| 维度 | 特征 |
|------|------|
| 核心城市 | 汕头、潮州、揭阳、普宁 |
| 文化标签 | 精明务实、宗族极强、功夫茶、重传统、潮商精神 |
| 消费心理 | ① 极度精明：货比三家是基本操作，对价格和品质都极其敏感 ② 宗族消费：全家/全族一起消费是常态 ③ 传统节日消费力极强：春节/中秋/元宵 ④ 面子消费：婚嫁/乔迁/开业消费力惊人 |
| 商业习俗 | ① 功夫茶文化：谈生意必泡茶 ② 老字号/老店信任度极高 ③ 口碑传播在宗族内极快 ④ "潮汕人帮潮汕人"：同乡推荐效力极强 |
| 消费高峰 | ① 春节（潮汕年味最浓） ② 中秋 ③ 元宵（潮州花灯） ④ 婚嫁季（国庆/春节前后） |
| 沟通偏好 | ① 务实直接，不喜欢花哨话术 ② 习惯用数据说话，重视算账式沟通 ③ 闽南语/潮汕话为日常语言，商业场合普通话为主 |
| 活动注意事项 | ① **精明客户需要"算账式"话术**：把省多少钱算清楚 ② **老店信任**：经营年数是最大背书，活动要强调"X年老店回馈" ③ **宗族推荐**：老带新在潮汕效力×5（一个家族推荐=一批客户） ④ **品质>价格**：潮汕人精明但不贪便宜，更看重性价比 ⑤ **传统节日营销**：潮汕传统节日消费力远超其他地区 |
| 活动话术风格 | ① 务实，用数据说话："这件原价800，现在买省200" ② 强调品质和性价比 ③ "您看这个面料/做工"比"这个最便宜"更有效 |
| 禁忌 | ① 不要用花哨营销话术，潮汕人一眼看穿 ② 不要低估客户的比价能力 ③ 不要忽视传统节日 |

## 3. 广府/珠三角地区（广州/佛山/东莞/中山/珠海）

| 维度 | 特征 |
|------|------|
| 核心城市 | 广州、佛山、东莞、中山、珠海、江门 |
| 文化标签 | 务实低调、饮茶文化、生活品质、国际化、新潮 |
| 消费心理 | ① 务实低调：不喜欢张扬，但愿意为品质花钱 ② 新潮：对新品/新品牌接受度高 ③ 理性消费：冲动消费少，计划消费多 ④ 饮茶社交：早茶/下午茶是重要社交场景 |
| 商业习俗 | ① 饮茶谈生意 ② 利是（红包）文化 ③ 开市/开工大吉 ④ 港澳影响：消费审美偏港风/简约 |
| 消费高峰 | ① 春节（花市/利是） ② 中秋 ③ 国庆 ④ 双11/双12（电商影响大） |
| 沟通偏好 | ① 务实简洁，不啰嗦 ② 粤语为日常语言，商业场合普通话通用 ③ 不喜欢被推销，反感过度热情 |
| 活动注意事项 | ① **低调务实**：活动不要太浮夸，"实惠""品质"比"限时抢购"更有效 ② **港风审美**：陈列/海报偏简约高级感 ③ **饮茶场景**：可结合"下午茶+试衣"体验 ④ **港澳消费外流**：部分高端客户去港澳消费，需强调"本地也能买到港货品质" ⑤ **新潮接受度高**：直播/短视频/线上引流效果好 |
| 活动话术风格 | ① 务实简洁，不啰嗦 ② "这件性价比很高"比"这件打5折"更打动 ③ 强调品质和实用性 |
| 禁忌 | ① 不要过度营销，广府人反感"被推销" ② 不要浮夸宣传 ③ 避免在饮茶时间打扰客户 |

## 5. 川渝地区（成都/重庆/绵阳/德阳）

| 消费心理 | ① 享乐主义：愿意为"巴适"花钱 ② 冲动消费比例高：看到喜欢就买 ③ 社交消费：和朋友一起消费是刚需 ④ 休闲文化：逛街=娱乐，不是任务 |
| 商业习俗 | ① 火锅社交：谈事/聚会=吃火锅 ② 茶馆文化：成都茶馆=社交中心 ③ 麻将社交：很多关系在麻将桌上建立 ④ 夜经济发达：晚上消费>白天 |
| 消费高峰 | ① 春节 ② 国庆 ③ 五一 ④ 周末（川渝周末消费力极强） |
| 沟通偏好 | ① 轻松幽默，像朋友聊天 ② 喜欢用四川话元素拉近距离 ③ 不喜欢被催促，偏好慢节奏沟通 |

| 活动话术风格 | ① 轻松幽默，像朋友聊天 ② "慢慢看嘛，不着急" ③ "这个穿起巴适得很" ④ 用四川话元素拉近距离 |
| 禁忌 | ① 不要催促客户决策 ② 不要太严肃/太商业 ③ 不要忽视周末和夜间消费 |

## 地域适配检查清单

在Phase 2诊断和Phase 3方案设计时，必须检查以下项目：

| # | 检查项 | 说明 |
|---|--------|------|
| 1 | 是否已确认用户具体城市？ | 只知道"福建"不够，必须知道"泉州/晋江/厦门" |
| 2 | 是否读取了对应区域的文化特征？ | 读取本文件对应区域 |
| 3 | 活动主题是否与当地文化契合？ | 如闽南中秋博饼、潮汕春节消费 |
| 4 | 活动话术是否适配当地沟通风格？ | 如闽南"阿姐"、川渝"巴适" |
| 5 | 是否避开了当地禁忌？ | 如闽南农历七月、西北穆斯林禁忌 |
| 6 | 优惠方式是否符合当地消费心理？ | 如闽南满额赠>折扣、中原折扣>赠礼 |
| 7 | 推广渠道是否适配当地习惯？ | 如江南小红书、长沙直播 |
| 8 | 是否利用了当地消费高峰？ | 如闽南佛诞日、潮汕春节 |
| 9 | 到店礼/赠品是否符合当地偏好？ | 如闽南茶叶、川渝火锅券 |
| 10 | 是否考虑了当地气候特征？ | 如东北冬季极寒、华南台风季 |
