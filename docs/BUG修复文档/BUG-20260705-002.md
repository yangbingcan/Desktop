## 三、第四轮修复（v0.5.5 终极修复 - 遮罩残留根因 + 按钮 ghost-type 适配）

> 用户在第三轮修复后反馈：点击主题设置按钮深色模式下仍然存在遮罩残留；浅色模式下商品档案查看/编辑按钮仍然显示不清晰（白色和透明底导致）。

### BUG-007：深色模式遮罩残留（终极根因）

| 项目 | 内容 |
|------|------|
| **现象** | 深色模式下点击主题设置按钮，关闭抽屉后仍有遮罩残留 |
| **根因** | `[data-theme='dark'] .n-drawer-container` CSS 规则匹配所有 container（包括空的）。Naive UI 关闭抽屉时先卸载 `.n-drawer` 但 `.n-drawer-container` 延迟卸载，空 container 被赋予 `#1F1812` 全屏背景（position:fixed, 100vw×100vh），造成视觉遮罩残留 |
| **位置** | `tea-manage/src/styles/n-overrides.css` 第 1217-1223 行 |
| **修复** | 1. 移除独立的 `.n-drawer-container` 选择器，改为 `.n-drawer .n-drawer-container`（需要 drawer 父元素）<br>2. 添加 `.n-drawer-container:empty, .n-modal-container:empty { display: none }` CSS 安全网<br>3. `cleanupLingeringMasks()` 增加清理空 container 逻辑 |
| **状态** | ✅ 已修复（Playwright 验证：空 container display:none, opacity:0, width:0, height:0） |

### BUG-008：浅色模式查看按钮文字白色不可见

| 项目 | 内容 |
|------|------|
| **现象** | 浅色模式下商品档案"查看"按钮文字为白色，透明背景，不可见 |
| **根因** | `globals.css` 第 602 行和 `n-overrides.css` 第 2285 行的 `.n-button--primary-type { color: var(--tea-content-inverse) !important }` 规则强制白色，没排除 `tea-btn-text`，覆盖了 `.tea-btn-text` 的茶金色（同特异性 0,0,1,0，后定义胜出） |
| **位置** | `tea-manage/src/styles/globals.css` 第 600-607 行 + `tea-manage/src/styles/n-overrides.css` 第 2284-2289 行 |
| **修复** | 给两处 `.n-button--primary-type` 规则添加 `:not(.n-button--ghost):not(.n-button--ghost-type):not(.tea-btn-text)` 排除 |
| **状态** | ✅ 已修复（Playwright 验证：查看按钮 color: rgb(196, 149, 106) 茶金色） |

### BUG-009：ghost 按钮被 regular 规则覆盖

| 项目 | 内容 |
|------|------|
| **现象** | 浅色模式下"编辑"按钮（ghost primary）有茶金色背景（应透明），文字白色（应茶金色）；"删除"按钮（ghost error）有红色背景（应透明），文字白色（应红色） |
| **根因** | Naive UI 的 ghost 按钮实际生成 `n-button--ghost-type` class（通过 Playwright 检查确认），但 CSS 规则用 `:not(.n-button--ghost)` 排除，不匹配 `n-button--ghost-type`，导致 ghost 按钮被 regular 按钮规则覆盖 |
| **位置** | `tea-manage/src/styles/n-overrides.css` 全文 57 处 `:not(.n-button--ghost)` + 8 处 `.n-button--ghost.xxx-type` 规则 |
| **修复** | 1. 全局替换 `:not(.n-button--ghost)` 为 `:not(.n-button--ghost):not(.n-button--ghost-type)`（57 处）<br>2. 给所有 `.n-button--ghost.xxx-type` 规则添加 `.n-button--ghost-type.xxx-type` 变体（primary/warning/success/info/error 5 种类型 + hover 状态） |
| **状态** | ✅ 已修复（Playwright 验证：编辑按钮 color: rgb(196, 149, 106), background: 透明；删除按钮 color: rgb(255, 77, 79), background: 透明） |

### BUG-010：cleanupLingeringMasks() 逻辑缺陷

| 项目 | 内容 |
|------|------|
| **现象** | 第三轮修复的 cleanupLingeringMasks() 函数无法正确判断抽屉是否可见 |
| **根因** | `maskEl.closest('.n-drawer')` 返回 null，因为 Naive UI 的 n-drawer 将 mask 和 drawer 渲染为兄弟节点（同在 .n-drawer-container 内），而非父子关系，导致 isParentVisible 永远为 false |
| **位置** | `tea-manage/src/stores/theme.ts` 第 148-192 行 |
| **修复** | 改用 `maskEl.closest('.n-drawer-container')` 找到容器，检查容器内是否有可见的 `.n-drawer` 子元素 |
| **状态** | ✅ 已修复 |

### 第五轮设计基准（ProductList.vue 操作列）

| 按钮 | 配置 | 视觉效果 |
|------|------|---------|
| 查看 | `text: true, class: 'tea-btn-text'` | 透明背景 + 茶金文字 + hover 淡茶金背景 |
| 编辑 | `ghost: true` | 透明背景 + 茶金边框 + 茶金文字 |
| 删除 | `type: 'error'`（实色，通过 NPopconfirm trigger） | 实色红背景 + 白色文字 |

### 第五轮设计原则

1. **操作层级可视化**：通过按钮风格区分操作权重
   - 查看类（低权重）→ text 按钮，最轻量
   - 编辑/详情类（中权重）→ ghost 按钮，有边框引导
   - 删除类（高权重 + 危险）→ 实色 error 按钮，强警示
2. **避免按钮同质化**：之前 3 个 text 按钮并列难以区分主次，调整后通过视觉差异明确操作层级
3. **删除按钮统一为实色 error**：删除是不可逆的破坏性操作，需要强视觉警示，不应使用 text 弱化

## 七、风险评估

### 7.1 主要风险

1. **Tauri 窗口控制按钮在 Web 预览模式下不工作**
   - 影响：开发预览模式下点击最小化/最大化/关闭无响应
   - 缓解：代码已通过 `__TAURI_INTERNALS__` 检测，Web 模式下静默降级，控制台警告但不报错
   - 验证：必须在 Tauri 桌面环境下 `npm run tauri dev` 完整验证

2. **`decorations: false` 在某些 Linux 窗口管理器下可能行为不一致**
   - 影响：Linux 下窗口可能无边框但无法移动
   - 缓解：已通过 `data-tauri-drag-region` 实现拖拽，覆盖大部分场景

### 7.2 回滚方案

如出现问题，可快速回滚：
1. `tauri.conf.json` 中 `decorations: false → true` 恢复原生标题栏
2. TitleBar.vue 中窗口控制按钮部分可单独移除（保留折叠 + TabBar + UserMenu）
3. 其他样式变更均为增量，不会影响功能

### BUG-007：遮罩残留（4 次反馈未解决）

| 项目 | 内容 |
|------|------|
| **现象** | 主题设置抽屉/弹窗关闭后仍有遮罩残留，特别是切换深色模式时 |
| **根因** | `applyToDOM()` 同步修改 `<html>` 的 `data-theme`/`data-primary` 等属性时触发全页样式重算，中断 Naive UI 抽屉/弹窗关闭时的 `fadeInTransition` opacity 过渡，导致 mask 卡在中间 opacity 状态 |
| **修复位置** | [theme.ts](file:///d:/AI/AI/开发/茶叶店管理/tea-manage/src/stores/theme.ts) 第 106-206 行、[n-overrides.css](file:///d:/AI/AI/开发/茶叶店管理/tea-manage/src/styles/n-overrides.css) 第 13-47 行 |
| **修复方案** | 1. 拆分 `applyToDOMInternal`（同步执行）+ `applyToDOM`（双 rAF 延迟）<br>2. 初始化时同步应用避免主题闪烁<br>3. 添加 `cleanupLingeringMasks()` 安全网，延迟 250ms 清理卡住的遮罩<br>4. CSS 添加 `leave-to`/`leave-active` 阶段强制 `opacity:0 + visibility:hidden` |
| **状态** | ✅ 已修复 |

### BUG-008：浅色主题查看/编辑按钮文字白色不可见

| 项目 | 内容 |
|------|------|
| **现象** | 商品档案操作列的"查看"/"编辑"按钮在浅色主题下文字为白色，与透明背景混合后不可见 |
| **根因** | `.n-button--primary-type { color: var(--tea-content-inverse) !important }` 等 regular 规则同时命中 ghost 按钮，覆盖了 ghost 按钮的对应色文字（透明背景 + 白字 = 不可见） |
| **修复位置** | [n-overrides.css](file:///d:/AI/AI/开发/茶叶店管理/tea-manage/src/styles/n-overrides.css) 第 397-466、2376-2401、2720-2751、2864-2877 行 |
| **修复方案** | 给所有 error/warning/success/info/primary 类型的 regular 规则添加 `:not(.n-button--ghost):not(.tea-btn-text)` 排除，确保 ghost 按钮不被 regular 按钮的白字规则覆盖 |
