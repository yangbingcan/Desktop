## 二、P0 · C1 路由鉴权（轻量会话门禁）

### 决策（已与用户确认）
登录页 `Login.vue` 本就是单机版 UI 壳（"本地单机版·任意账号密码即可进入演示"），**无后端用户表/密码校验**。因此"修鉴权"的选项是：
- ✅ **轻量会话门禁**：登录写 `localStorage` 标记，路由守卫未登录且非 `public` 路由则重定向 `/login`。
- 不引入完整登录体系（无用户表，属架构级新增，需另立需求）。

### 改动清单
1. **`src/router/index.ts`** — `beforeEach` 守卫从无条件 `next()` 改为读取登录态：
   ```ts
   router.beforeEach((to, _from, next) => {
       document.title = `${to.meta.title || '茶易管'} - 茶易管`
       const isPublic = to.meta?.public === true
       const loggedIn = localStorage.getItem('tea-logged-in') === '1'
       if (!loggedIn && !isPublic) {
           next('/login')
       } else if (loggedIn && to.name === 'Login') {
           next('/')
       } else {
           next()
       }
   })
   ```
   `/login` 路由已声明 `meta: { public: true }`（原 M3 死配置由此被激活）。

2. **`src/views/auth/Login.vue`** — `handleLogin` 在 `saveRememberedLogin(...)` 之后追加：
   ```ts
   localStorage.setItem('tea-logged-in', '1')
   ```

### 效果
- 未登录访问任意业务路由 → 强制跳转 `/login`。
- 已登录再访问 `/login` → 重定向首页，避免重复登录。
- 单机演示场景：任意账号密码登录后即写入标记，功能不受影响。

## 三、P0 · C2 金额浮点漂移（边界四舍五入）

### 决策（已与用户确认）
用户选择**保留 SQLite `REAL`（f64）存储不动 schema**，仅在**聚合/落库边界**用可参数化四舍五入 helper 收敛精度。理由：14 个金额列全为 `REAL`，改 `i64` 分或 `rust_decimal` 属 DB schema 级破坏性变更，需另立迁移需求。

### 新增文件
- **`src-tauri/src/utils/money.rs`**（含 `src-tauri/src/utils/mod.rs` 模块声明）：
  ```rust
  pub enum RoundMode { HalfUp, HalfDown, Up, Down }
  pub fn round_money(value: f64, decimals: u32, mode: RoundMode) -> f64 {
      if !value.is_finite() { return 0.0; }
      let factor = 10f64.powi(decimals as i32);
      let scaled = value * factor;
      let rounded = match mode {
          RoundMode::HalfUp  => (scaled + 0.5).floor(),
          RoundMode::HalfDown => (scaled - 0.5).ceil(),
          RoundMode::Up      => scaled.ceil(),
          RoundMode::Down    => scaled.floor(),
      };
      rounded / factor
  }
  pub fn round2(value: f64) -> f64 { round_money(value, 2, RoundMode::HalfUp) }
  ```
  - 支持 `四舍五入/四舍五入不进位(HalfDown)/进位(Up)/截断(Down)` 与保留位数参数化，满足用户"两个参数控制"的要求。
  - 非有限值（NaN/Inf）归零，防落库污染。

- **`src-tauri/src/lib.rs`** — 注册 `pub mod utils;`（修复编译报错 E0583 的配套动作，见第九节）。

### 应用边界（均包 `round2`）
| 文件 | 收敛点 |
|------|--------|
| `commands/sales.rs` | `subtotal`、`total_amount`、`discount`/`after_discount`、`points_deduct_amount`、`actual_amount`、`new_total_consume`、`new_balance`；挂单路径 `item_subtotal` 与汇总前 `total_amount` |
| `commands/return_order.rs` | 两处 `subtotal = purchase_price * qty`、`total_amount`（创建退货单/主单前） |
| `commands/members.rs` | 充值 `new_balance = current + amount`、`amount`/`bonus_amount` 入参；退款 `new_balance = current - amount` |
| `commands/supplier_payments.rs` | 入参 `amount`、已付总额与订单总额查询后归一 |

> 说明：`subtotal`/`total_amount` 等聚合结果在写入前统一 `round2`，避免多笔累加的 `0.005` 级浮点漂移累计进账目。
