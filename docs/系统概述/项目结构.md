# 项目结构 - 管用GL

> **文档版本**：v3.0
> **最后更新**：2026-06-04

---

## 一、项目总体结构

管用GL采用 **Tauri 2.x** 架构，前端 React 应用通过 WebView 渲染，后端 Rust 通过 Tauri Command 暴露 API，服务端通过 `path` 依赖复用核心业务库。

```
guanyong-gl/
├── src-tauri/                   # Tauri 核心（Rust 后端 + 配置）
│   ├── src/                     # Rust 源码
│   ├── Cargo.toml               # Rust 依赖配置
│   ├── tauri.conf.json          # Tauri 配置
│   ├── build.rs                 # Tauri 构建脚本
│   └── icons/                   # 应用图标
├── src/                         # React 前端源码
│   ├── app/                     # 应用入口与路由
│   ├── pages/                   # 页面组件
│   ├── components/              # 公共组件
│   ├── hooks/                   # 自定义 Hooks
│   ├── stores/                  # Zustand 状态管理
│   ├── services/                # API 服务层（Tauri IPC / HTTP RPC）
│   ├── styles/                  # 全局样式
│   ├── types/                   # TypeScript 类型定义
│   └── utils/                   # 工具函数
├── server/                      # 独立服务端二进制（局域网/云版）
│   ├── src/
│   │   ├── main.rs              # 服务端入口
│   │   └── bin/
│   │       └── keygen.rs        # 激活码生成工具
│   └── Cargo.toml               # 依赖 src-tauri 核心库
├── public/                      # 静态资源
├── index.html                   # HTML 入口
├── vite.config.ts               # Vite 配置
├── tailwind.config.ts           # Tailwind CSS 配置
├── tsconfig.json                # TypeScript 配置
├── package.json                 # 前端依赖
├── specs/                       # 项目规范文档
├── docs/                        # 项目文档
├── templates/                   # 项目模板
└── .trae/                       # AI 开发配置
```

## 三、Rust 后端结构（src-tauri/src/）

```
src-tauri/src/
├── lib.rs                       # 模块声明 + Tauri Builder 注册所有 command
├── main.rs                      # Tauri 应用入口（调用 lib::run()）
├── server.rs                    # Axum HTTP 服务器（RPC 路由 + SSE 事件推送）
├── database.rs                  # SQLite 初始化、连接管理、版本化迁移
├── models.rs                    # 所有数据模型结构体定义
├── error_util.rs                # 错误中文化翻译工具
├── auth.rs                      # 用户认证
├── operation_logs.rs            # 操作日志
├── system_config.rs             # 系统配置
├── roles.rs                     # 角色权限
└── ...                          # 后续业务模块
```

## 四、目录说明

| 目录 | 用途 | 说明 |
|------|------|------|
| `src/` | 前端应用 | React 18 + Ant Design 5 + Zustand + Tailwind CSS |
| `src-tauri/` | Tauri 核心 | Rust 后端 + Tauri 配置 |
| `server/` | 独立服务端 | Rust Axum HTTP 服务器（局域网/云版） |
| `public/` | 静态资源 | 图标、字体等 |
| `specs/` | 项目规范 | 需求、设计、UI 规范等文档 |
| `docs/` | 项目文档 | 系统概述、开发记录等 |
| `templates/` | 项目模板 | 技能模板、工作流模板 |

## 五、命名规范

| 类型 | 规范 | 示例 |
|------|------|------|
| 前端目录名 | kebab-case | `form-designer/`、`data-center/` |
| React 组件文件 | PascalCase.tsx | `FormCanvas.tsx`、`DataGrid.tsx` |
| Hook 文件 | useXxx.ts | `useAuth.ts`、`usePermission.ts` |
| 工具/服务文件 | camelCase.ts | `format.ts`、`productService.ts` |
| 样式文件 | kebab-case.css | `ant-overrides.css` |
| Rust 模块文件 | snake_case.rs | `warehouse_ops.rs`、`error_util.rs` |
| Rust 函数名 | snake_case | `get_products`、`create_sale_order` |
| TypeScript 类型 | PascalCase | `Product`、`SaleOrder` |
